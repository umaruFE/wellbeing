# Classroom font sources and OFL notes

Prepared (UTC): 2026-10-17T09:20:10.644856+00:00

## Files and scope

- `classroom-latin-regular.woff2` and `classroom-latin-bold.woff2`: local subsets of the requested Noto Sans Regular/Bold source fonts at `/opt/codex/runtimes/codex-primary-runtime/dependencies/native/libreoffice-headless/libreoffice/share/fonts/truetype`. Requested ranges: U+0000–024F, U+2000–206F, U+2190–2193. Only source-covered characters can be retained. Source-covered requested code points were verified after WOFF2 reconstruction.
- `classroom-noto-sans-sc.woff2`: local subset of the official Google Fonts repository Noto Sans SC variable font. Weight axis is limited to 400–700. The subset includes every Chinese, CJK-punctuation, and fullwidth character found in the current `music-classroom-wrap-check.html`, plus common testing labels, punctuation, and ASCII. Rebuild when new Chinese labels are introduced.

## Official Chinese source and privacy-preserving preparation

- Standard Google Fonts CSS2 family metadata, with **no `text` parameter**: https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400..700&display=swap
- Complete official source font: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
- Noto Sans SC OFL: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/OFL.txt
- Noto Sans OFL: https://raw.githubusercontent.com/google/fonts/main/ofl/notosans/OFL.txt

The requested server-side CSS2 `text` subset could not be used because automatic approval review rejected transmitting characters derived from a local project to Google. The safe alternative downloaded only fixed, public dependency URLs and performed all character extraction and subsetting locally. No local HTML text or derived character list was sent to Google, GitHub, or another external service. The full source font and CSS were processed in memory; only the final WOFF2 files and these source/license notes are saved here.

## Validation

Each resulting WOFF2 was checked for `wOF2` signature and declared byte length, decompressed through fontTools using Node native Brotli, and parsed for character maps and glyph tables. The Latin files retained all requested characters available in their source fonts. The Chinese file has zero missing required local characters. These checks establish valid font files and coverage; they are not browser layout or real classroom reading tests.

## Embedding CSS

For a standalone HTML artifact, replace each URL with its `data:font/woff2;base64,...` form. The Latin family comes first so English uses the same font on every test system; the SC family supplies Chinese fallback. Apply the stack to the classroom, test controls, and form elements. Before screenshots or wrap measurements, await `document.fonts.ready` and check that the requested faces loaded.

```css
@font-face { font-family: 'Classroom Noto Sans'; src: url('./assets/classroom-latin-regular.woff2') format('woff2'); font-style: normal; font-weight: 400; font-display: swap; }
@font-face { font-family: 'Classroom Noto Sans'; src: url('./assets/classroom-latin-bold.woff2') format('woff2'); font-style: normal; font-weight: 700; font-display: swap; }
@font-face { font-family: 'Classroom Noto Sans SC'; src: url('./assets/classroom-noto-sans-sc.woff2') format('woff2'); font-style: normal; font-weight: 400 700; font-display: swap; }
/* Use this stack on the classroom root, test UI, and form controls. */
font-family: 'Classroom Noto Sans', 'Classroom Noto Sans SC', sans-serif;
```
