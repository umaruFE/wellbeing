## 一、系统简介

Wellbeing 是一个 **AI 驱动的少儿英语课程创作平台**。通过 AI 自动生成课程内容、教案、PPT 课件和教学素材（图片/音频/视频），帮助教师高效完成课程开发。

**核心工作流程**：

```
创建课程 → 课程地图 → 教案设计 → PPT 课件 → 发布
```

**4E 教学法**：所有教案围绕四个阶段组织：
- **Engage（引入）**：激发兴趣，导入情境
- **Empower（赋能）**：语言输入，知识建构
- **Execute（实践）**：活动练习，语言输出
- **Elevate（升华）**：反思总结，情感升华

## 二、登录与账户

### 2.1 登录

1. 打开系统访问地址，进入登录页
2. 输入**用户名**和**密码**

### 2.2 角色说明

|------|------|---------|

页面右上角可切换 **中文 / English**，切换后界面和 AI 生成内容语言同步变化。

## 四、创建课程（4 步向导）

### 步骤一：设定课程

填写课程基础信息：

| 字段 | 说明 | 是否必填 |
|------|------|---------|
| 年龄段 | 3-6 / 7-9 / 9-12 岁 | ✅ 必填 |
| 课程时长 | 40 / 60 / 120 分钟 | ✅ 必填 |
| 班级人数 | ≤8 / 9-15 / ≥16 人 | ✅ 必填 |
| 核心词汇 | 输入词汇后回车添加为标签，**支持粘贴批量解析**（逗号/换行分隔） | ✅ 必填 |
| 核心句型 | 输入句型后回车添加，**支持按句号智能拆分** | ✅ 必填 |
| 语言技能 | 听力 / 口语 / 阅读 / 写作 / 综合（多选） | 选填 |

> 💡 **技巧**：可以直接粘贴如 `sport, bike, friend, run, jump` 到词汇框，系统会自动拆分为多个标签。

### 步骤二：设计冒险

设计课程的情境任务：

| 字段 | 说明 | 是否必填 |
|------|------|---------|
| 任务名称 | 本次课程的情境任务名称 | ✅ 必填 |
| 情境故事 | 课堂的故事背景设定 | ✅ 必填 |
| 关键产出 | 学生最终完成的成果 | ✅ 必填 |

> 💡 **AI 辅助**：
> - 点击「**获取灵感**」让 AI 生成创意任务名称
> - 点击「**润色内容**」让 AI 优化你输入的文本

### 步骤三：选择路径

选择课堂的**体验路径**（可多选）：

- 🎨 **艺术表达**：绘画、手工、创作
- 🏃 **体感探索**：运动、游戏、肢体活动
- 🎵 **音乐律动**：歌曲、节奏、音乐活动

### 步骤四：添加魔法

个性化设置（选填）：

- **特殊要求**：对课程的额外要求
- **课堂氛围**：神秘探险感 / 戏剧表演感 / 温馨治愈感 / 团队协作感

### 提交

点击「提交」后，系统自动调用 AI：
1. 生成**课程概览**（标题、情境、目标、旅程）
2. 生成**主题封面图**
3. 保存为草稿课程，自动进入课程创作工作流

> ⏱️ AI 生成约需 15-30 秒，请耐心等待。

## 六、课程地图

进入课程后，第一个页面就是**课程地图**，展示 AI 生成的课程总览。

### 6.1 查看课程信息

- **封面卡片**：课程标题、年龄、时长、班级人数、体验路径
- **核心情境**：点击可展开查看完整故事背景
- **主题封面图**：AI 生成的课程封面

### 6.2 四大目标卡片

| 卡片 | 内容 |
|------|------|
| 语言工具箱 | 核心词汇 + 核心句型 |
| 关键产出 | 学生最终成果任务 |
| 成长罗盘 | SEL 社会情感目标 + PERMA 幸福目标 |
| 学习方式 | 体验路径说明 |

> 点击任意卡片可展开查看完整内容。

### 6.3 课堂旅程

展示 Engage / Empower / Execute / Elevate 四个阶段的课堂旅程描述。

### 6.4 编辑课程地图

- **直接编辑**：点击「编辑」按钮，直接修改文本字段（不调 AI）
- **AI 重新生成**：
  1. 点击「重新生成」
  2. 系统先给出**调整建议**（快捷 chips）
  3. 选择建议或输入自定义调整需求
  4. 确认后 AI 重新生成课程概览

### 6.5 重新生成封面图

点击封面图区域的「重新生成」，AI 会生成新的主题封面图。

## 七、教案设计

教案设计是系统的核心模块，基于 4E 教学法组织教学环节。

### 7.1 首次生成

首次进入教案设计时，如果没有数据，系统会**自动调用 AI 生成完整教案**（约 30-60 秒）。

### 7.2 视图模式

两种视图可切换：

| 模式 | 说明 |
|------|------|
| **地图模式** | 游戏地图背景，四阶段以节点展示，点击节点打开侧边抽屉查看详情 |
| **概览模式** | 看板式四列布局，每列展示该阶段所有环节卡片 |

### 7.3 环节操作

每个教学环节卡片支持以下操作（点击右上角菜单）：

| 操作 | 说明 |
|------|------|
| **重新生成** | AI 重新生成该环节 |
| **调整环节** | 输入调整思路，AI 按需求调整（弹窗保持 loading） |
| **收藏此环节** | 保存到「我的收藏」，方便复用 |
| **取消收藏** | 取消已收藏的环节 |
| **置顶** | 将环节移到阶段首位 |
| **删除** | 删除该环节 |

底部操作栏：
- **查看详情**：只读查看环节全部信息
- **编辑**：打开编辑表单，可修改所有字段
- **调整**：快捷进入 AI 调整

### 7.4 添加环节

点击阶段卡片中的「添加环节」按钮，弹出三 Tab 选择：

#### Tab 1：AI 生成
1. 选择提示词快捷 chips（角色扮演/小组合作/游戏化/真实情境/动手操作）或自由输入
2. 点击「AI 生成草案」
3. AI 生成后可在右侧表单中预览和微调
4. 点击「确认添加」

#### Tab 2：经典活动
直接选择预设的经典教学活动（Bingo、猜单词、情景对话、闪卡翻转、拼图阅读、我画你猜）。

#### Tab 3：我的收藏
从已收藏的环节中选择复用。

### 7.5 调整环节

1. 点击菜单中的「调整环节」
2. 在弹窗中填写**调整思路**（必填）
3. 可选择快捷提示词 chips
4. 可勾选 6 大调整方向：
   - 基础设计、语言目标、体验互动、学习者匹配、教师操作、叙事连贯性
5. 点击确认，弹窗显示 loading，AI 调整完成后自动更新

### 7.6 自动保存

> 💡 所有增删改操作都会**自动保存**到后端，阶段总时长也会**实时更新**。无需手动保存。

### 7.7 重新生成整个阶段

在阶段卡片中点击「重新生成」，AI 会重新生成该阶段的所有环节。

## 八、PPT 课件制作

### 8.1 生成 PPT 内容

1. 选择 **PPT 模板**
2. 设置**预估页数**（步进器调整）
3. 点击「生成课件」
4. AI 自动生成英文 PPT 内容与布局（约 30-60 秒）

### 8.2 编辑器布局

生成后进入三栏编辑器：

```
┌─────────┬─────────────────┬──────────┐
│  大纲    │     画布         │ 属性面板  │
│ (左栏)   │   (中间区域)      │ (右栏)   │
├─────────┤                 ├──────────┤
│ 封面页   │   [幻灯片预览]    │ 文本样式  │
│ Engage  │                 │ 图片配置  │
│ Empower │                 │ 视频配置  │
│ Execute │                 │ 音频配置  │
│ Elevate │                 │ AI素材    │
└─────────┴─────────────────┴──────────┘
```

### 8.3 画布操作

| 操作 | 方法 |
|------|------|
| 移动元素 | 鼠标拖拽 |
| 缩放元素 | 拖拽 8 方向缩放手柄 |
| 旋转元素 | 拖拽旋转手柄 |
| 编辑文本 | 双击文本元素 |
| 删除元素 | 选中后按 Delete |
| 复制元素 | 选中后按 Ctrl+D |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y |
| 取消选中 | Esc |
| 微移元素 | 方向键（Shift 加速） |
| 缩放画布 | 缩放控件 35%-120% |

> 💡 拖拽元素靠近其他元素或画布边缘时，会显示**对齐辅助线**帮助对齐。

### 8.4 幻灯片管理（左侧大纲）

- 点击**封面页**或各阶段展开/折叠
- 每个环节下展示幻灯片缩略图
- **添加幻灯片**：点击 + 按钮
- **删除幻灯片**：点击缩略图上的删除按钮
- **复制幻灯片**

### 8.5 图层操作（顶部工具栏）

| 操作 | 方法 |
|------|------|
| 插入文本 | 工具栏 → 文本 |
| 插入图片 | 工具栏 → 图片 |
| 插入视频 | 工具栏 → 视频 |
| 插入音频 | 工具栏 → 音频 |
| 设为背景 | 右键 → 设为背景 |
| 调整层级 | 右键 → 上移/下移图层 |
| 居中 | 右键 → 居中 |
| 适应画布 | 右键 → 适应画布 |

### 8.6 AI 素材生成（右侧面板）

点击右侧面板的「AI 素材」标签，可生成三种素材：

#### 图片素材（12+ 种类型）

| 代码 | 类型 | 说明 |
|------|------|------|
| B1 | 主题场景图 | 课程主题背景图 |
| B2 | 带文字场景图 | 含教学文字的图 |
| B3 | 词汇闪卡 | 批量生成词汇卡 |
| B4 | 故事插画 | 故事情节配图 |
| B5 | 活动氛围图 | 课堂活动场景 |
| B6 | 主题词云 | 词汇可视化 |
| B7 | 文本配图 | 段落配图 |
| B8 | 知识总结图 | 思维导图/表格/鱼骨图/树状图 |
| B9 | 绘本配图 | 多页一致性插画 |
| B10 | 四格漫画 | 漫画风格 |
| B11 | IP 角色动作图 | Poppy/Edi/Rolly/Milo/Ace 角色动作 |
| B13 | 多人场景 | 多角色互动场景 |

**操作步骤**：
1. 选择图片类型
2. 配置选项（画风、比例、留白方向、主题等）
3. 点击「生成」
4. 等待生成完成（10-30 秒）
5. 在结果中**选择**需要的图片
6. 点击「插入」/「作为背景」/「多页插入」

#### 视频素材
- V1：IP 角色体能视频
- VM：多人叙事视频

#### 音频素材
- C1：情绪氛围背景乐
- C2：活动背景乐
- C3：跟读朗读音频
- C4：对话配音
- C5：教学歌曲
- C6：冥想引导音频

### 8.7 导出 PPT

点击顶部「导出 .pptx」按钮，系统将课件导出为 PowerPoint 文件下载到本地。

## 十、绘本制作

### 10.1 上传知识库

1. 进入「绘本知识库上传」
2. 上传教学资料（PDF/Word 等）
3. 系统自动清洗、切片、生成向量索引

### 10.2 生成绘本

1. 进入「绘本制作」
2. 输入绘本主题和设定
3. 点击「生成」
4. 系统 RAG 检索知识库 → AI 生成多页故事文案 + 逐页配图
5. 右侧侧边栏展示已生成页数和缩略图

> 💡 绘本配图会保持**角色和画风一致性**。

## 十二、任务中心

任务中心管理所有 AI 异步生成任务。

### 12.1 查看任务

- **当前队列**：进行中、等待中的任务
- **历史记录**：已完成、失败的任务
- 列表每 5 秒自动刷新

### 12.2 任务状态

| 状态 | 说明 |
|------|------|

### 12.3 任务操作

| 操作 | 方法 |
|------|------|

| 重新提交 | 失败任务点击「重新提交」 |
| 插入画布 | 完成的任务点击「插入画布」直接使用结果 |

### 13.1 用户管理

## 十四、常见问题

### Q1：AI 生成一直转圈不返回？

**A**：AI 生成通常需要 15-60 秒。如果超过 2 分钟无响应：
1. 检查网络连接
2. 查看「任务中心」是否有失败任务
3. 刷新页面重试
4. 联系管理员检查 n8n 服务状态

### Q2：教案环节的步骤标题显示为"步骤 1"？

**A**：这是因为 AI 偶尔未按"名称：内容"格式输出。这是正常的兜底显示，不影响内容质量。可以手动编辑环节修改标题。

### Q3：课程生成失败，提示"未能获取课件数据"？

**A**：通常是 n8n 工作流返回了空响应。请：
1. 稍后重试
2. 联系管理员检查 n8n 服务和 DeepSeek API 状态

### Q4：PPT 导出后样式有差异？

**A**：pptxgenjs 导出为标准 PPT 格式，部分自定义样式（如旋转、复杂描边）可能略有差异。建议导出后在 PowerPoint 中微调。

### Q5：如何让多人协作编辑同一课程？

**A**：目前系统不支持实时多人协作。建议一人负责编辑，通过「发布」和「课程广场」分享给他人查看或复制。

### Q6：收藏的环节在哪里查看？

**A**：在教案设计中，点击「添加环节」→ 切换到「我的收藏」Tab，即可查看所有已收藏的环节。

### Q7：素材生成消耗算力吗？

**A**：是的，所有 AI 生成（图片/视频/音频）都会消耗算力额度。可在工作台首页的「资产总览」查看剩余额度。

### Q8：如何切换界面语言？

**A**：点击页面右上角的语言切换按钮，可在中文/English 之间切换。AI 生成的内容也会根据当前语言输出。

### Q9：自动保存失败了怎么办？

**A**：顶部会显示保存状态（saving/saved/error）。如果显示 error：
1. 检查网络连接
2. 点击「保存」按钮手动重试
3. 系统有 localStorage 草稿缓存，数据不会丢失

### Q10：如何删除不需要的课程？

**A**：在「课程管理」页面，点击课程卡片上的删除按钮，确认后即可删除。删除操作不可恢复，请谨慎操作。
