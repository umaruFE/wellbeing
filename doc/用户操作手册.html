一、系统简介

Wellbeing 是一个 AI 驱动的少儿英语课程创作平台。通过 AI 自动生成课程内容、教案、PPT 课件和教学素材（图片/音频/视频），帮助教师高效完成课程开发。

核心工作流程：

创建课程 → 课程地图 → 教案设计 → PPT 课件 → 发布

4E 教学法：所有教案围绕四个阶段组织：

  • Engage（引入）：激发兴趣，导入情境
  • Empower（赋能）：语言输入，知识建构
  • Execute（实践）：活动练习，语言输出
  • Elevate（升华）：反思总结，情感升华

二、登录与账户

2.1 登录

  1. 打开系统访问地址，进入登录页
  2. 输入用户名和密码
  3. 点击「登录」按钮
  4. 登录成功后自动跳转到工作台首页

2.2 角色说明

角色 说明 可用功能
超级管理员 系统最高权限 全部功能 + 系统设置 + 账号管理
机构管理员 机构级管理 全部课程功能 + 机构管理
教研组长 教研管理 全部课程创作功能

2.3 语言切换

页面右上角可切换 中文 / English，切换后界面和 AI 生成内容语言同步变化。

四、创建课程（4 步向导）

步骤一：设定课程

填写课程基础信息：

字段 说明 是否必填
年龄段 3-6 / 7-9 / 9-12 岁 ✅ 必填
课程时长 40 / 60 / 120 分钟 ✅ 必填
班级人数 ≤8 / 9-15 / ≥16 人 ✅ 必填
核心词汇 输入词汇后回车添加为标签，支持粘贴批量解析（逗号/换行分隔） ✅ 必填
核心句型 输入句型后回车添加，支持按句号智能拆分 ✅ 必填
语言技能 听力 / 口语 / 阅读 / 写作 / 综合（多选） 选填

💡 技巧：可以直接粘贴如 sport, bike, friend, run, jump 到词汇框，系统会自动拆分为多个标签。

步骤二：设计冒险

设计课程的情境任务：

字段 说明 是否必填
任务名称 本次课程的情境任务名称 ✅ 必填
情境故事 课堂的故事背景设定 ✅ 必填
关键产出 学生最终完成的成果 ✅ 必填

💡 AI 辅助：

  • 点击「获取灵感」让 AI 生成创意任务名称
  • 点击「润色内容」让 AI 优化你输入的文本

步骤三：选择路径

选择课堂的体验路径（可多选）：

  • 🎨 艺术表达：绘画、手工、创作
  • 🏃 体感探索：运动、游戏、肢体活动
  • 🎵 音乐律动：歌曲、节奏、音乐活动

步骤四：添加魔法

个性化设置（选填）：

  • 特殊要求：对课程的额外要求
  • 课堂氛围：神秘探险感 / 戏剧表演感 / 温馨治愈感 / 团队协作感

提交

点击「提交」后，系统自动调用 AI：

  1. 生成课程概览（标题、情境、目标、旅程）
  2. 生成主题封面图
  3. 保存为草稿课程，自动进入课程创作工作流

⏱️ AI 生成约需 15-30 秒，请耐心等待。

5.4 操作课程

操作 方法
进入编辑 点击课程卡片
删除课程 点击卡片上的删除按钮 → 确认删除

六、课程地图

进入课程后，第一个页面就是课程地图，展示 AI 生成的课程总览。

6.1 查看课程信息

  • 封面卡片：课程标题、年龄、时长、班级人数、体验路径
  • 核心情境：点击可展开查看完整故事背景
  • 主题封面图：AI 生成的课程封面

6.2 四大目标卡片

卡片 内容
语言工具箱 核心词汇 + 核心句型
关键产出 学生最终成果任务
成长罗盘 SEL 社会情感目标 + PERMA 幸福目标
学习方式 体验路径说明

点击任意卡片可展开查看完整内容。

6.3 课堂旅程

展示 Engage / Empower / Execute / Elevate 四个阶段的课堂旅程描述。

6.4 编辑课程地图

  • 直接编辑：点击「编辑」按钮，直接修改文本字段（不调 AI）
  • AI 重新生成：
    1. 点击「重新生成」
    2. 系统先给出调整建议（快捷 chips）
    3. 选择建议或输入自定义调整需求
    4. 确认后 AI 重新生成课程概览

6.5 重新生成封面图

点击封面图区域的「重新生成」，AI 会生成新的主题封面图。

七、教案设计

教案设计是系统的核心模块，基于 4E 教学法组织教学环节。

7.1 首次生成

首次进入教案设计时，如果没有数据，系统会自动调用 AI 生成完整教案（约 30-60 秒）。

7.2 视图模式

两种视图可切换：

模式 说明
地图模式 游戏地图背景，四阶段以节点展示，点击节点打开侧边抽屉查看详情
概览模式 看板式四列布局，每列展示该阶段所有环节卡片

7.3 环节操作

每个教学环节卡片支持以下操作（点击右上角菜单）：

操作 说明
重新生成 AI 重新生成该环节
调整环节 输入调整思路，AI 按需求调整（弹窗保持 loading）
收藏此环节 保存到「我的收藏」，方便复用
取消收藏 取消已收藏的环节
置顶 将环节移到阶段首位
删除 删除该环节

底部操作栏：

  • 查看详情：只读查看环节全部信息
  • 编辑：打开编辑表单，可修改所有字段
  • 调整：快捷进入 AI 调整

7.4 添加环节

点击阶段卡片中的「添加环节」按钮，弹出三 Tab 选择：

Tab 1：AI 生成

  1. 选择提示词快捷 chips（角色扮演/小组合作/游戏化/真实情境/动手操作）或自由输入
  2. 点击「AI 生成草案」
  3. AI 生成后可在右侧表单中预览和微调
  4. 点击「确认添加」

Tab 2：经典活动

直接选择预设的经典教学活动（Bingo、猜单词、情景对话、闪卡翻转、拼图阅读、我画你猜）。

Tab 3：我的收藏

从已收藏的环节中选择复用。

7.5 调整环节

  1. 点击菜单中的「调整环节」
  2. 在弹窗中填写调整思路（必填）
  3. 可选择快捷提示词 chips
  4. 可勾选 6 大调整方向：
    • 基础设计、语言目标、体验互动、学习者匹配、教师操作、叙事连贯性
  5. 点击确认，弹窗显示 loading，AI 调整完成后自动更新

7.6 自动保存

💡 所有增删改操作都会自动保存到后端，阶段总时长也会实时更新。无需手动保存。

7.7 重新生成整个阶段

在阶段卡片中点击「重新生成」，AI 会重新生成该阶段的所有环节。

十四、常见问题

Q1：AI 生成一直转圈不返回？

A：AI 生成通常需要 15-60 秒。如果超过 2 分钟无响应：

  1. 检查网络连接
  2. 查看「任务中心」是否有失败任务
  3. 刷新页面重试
  4. 联系管理员检查 n8n 服务状态

Q2：教案环节的步骤标题显示为"步骤 1"？

A：这是因为 AI 偶尔未按"名称：内容"格式输出。这是正常的兜底显示，不影响内容质量。可以手动编辑环节修改标题。

Q3：课程生成失败，提示"未能获取课件数据"？

A：通常是 n8n 工作流返回了空响应。请：

  1. 稍后重试
  2. 联系管理员检查 n8n 服务和 DeepSeek API 状态

Q4：PPT 导出后样式有差异？

A：pptxgenjs 导出为标准 PPT 格式，部分自定义样式（如旋转、复杂描边）可能略有差异。建议导出后在 PowerPoint 中微调。

Q5：如何让多人协作编辑同一课程？

A：目前系统不支持实时多人协作。建议一人负责编辑，通过「发布」和「课程广场」分享给他人查看或复制。

Q6：收藏的环节在哪里查看？

A：在教案设计中，点击「添加环节」→ 切换到「我的收藏」Tab，即可查看所有已收藏的环节。

Q7：素材生成消耗算力吗？

A：是的，所有 AI 生成（图片/视频/音频）都会消耗算力额度。可在工作台首页的「资产总览」查看剩余额度。

Q8：如何切换界面语言？

A：点击页面右上角的语言切换按钮，可在中文/English 之间切换。AI 生成的内容也会根据当前语言输出。

Q9：自动保存失败了怎么办？

A：顶部会显示保存状态（saving/saved/error）。如果显示 error：

  1. 检查网络连接
  2. 点击「保存」按钮手动重试
  3. 系统有 localStorage 草稿缓存，数据不会丢失

Q10：如何删除不需要的课程？

A：在「课程管理」页面，点击课程卡片上的删除按钮，确认后即可删除。删除操作不可恢复，请谨慎操作。
