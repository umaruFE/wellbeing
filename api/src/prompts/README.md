# 大模型提示词

项目中由代码直接发送给大模型或 N8N 大模型工作流的核心提示词统一维护在此目录。

- `picture-book.ts`：引导式绘本活动方案与逐页设计
- `song-writing.ts`：儿童英语歌曲创编
- `video.ts`：视频描述优化与分镜脚本生成
- `course-journey.ts`：课堂旅程生成
- `index.ts`：统一导出入口

约定：

1. 路由中不直接编写 system/user prompt 长文本。
2. 固定提示词使用具名常量，含业务参数的提示词使用 `build...Prompt` 函数。
3. 构造函数只拼装文本，不访问网络、数据库或环境变量，方便单独测试和排查。
4. 用户原始输入、图片模型的普通素材描述和 UI 占位文案不属于本目录。
