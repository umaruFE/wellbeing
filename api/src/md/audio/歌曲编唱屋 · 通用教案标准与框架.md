| 1.2 元素配对   | 2 min  | 将主题元素与另一种感官载体配对（如情绪→乐器、词汇→动作、颜色→声音）     | 配对应有"为什么这样配"的联想空间，不是机械对应    |

**教学引导撰写规则：**

* 过渡语必须用英文写，因为这是课堂中实际说的

### 环节二：歌曲创编（约 8 min）

**定位**：这是歌曲编唱屋的核心环节。学生从"听歌的人"变成"写歌的人"。

**子步骤模板：**

#### 2.1 熟悉旋律（0.5 min）

* 播放歌曲旋律，跟随旋律自由哼唱
* 不要求跟唱歌词，只建立旋律感

#### 2.2 理解歌词结构（2 min）

* 逐行带读歌词，空格处停顿或说"bla-bla"
* 指出重复出现的核心句型
* 指出"点题句"（通常每段最后一行），解释其含义

#### 2.3 集体填词（5-6 min）

* 从 Word Bank 中拖拽词汇填入空格
* 引导师逐空提问，学生举手提议，由学生或引导师操作屏幕

**填词引导表模板：**

```markdown
| 空格 | 歌词线索 | 引导提问 | 推荐选择 |
|------|---------|---------|---------|
| 1 | "歌词原文" | 英文开放提问 | 2-3 个可能方向 |
| 2 | "歌词原文" | 英文开放提问 | 2-3 个可能方向 |
| … | … | … | … |
```

**填词引导表撰写规则：**

* 「歌词线索」列：只摘录歌词中包含线索的那几个词，不全行抄
* 「引导提问」列：用英文写课堂中实际问出的问题，开放、好奇，不是"对不对"
* 「推荐选择」列：写 2-3 个可能方向，标注"仅供参考"；不写唯一答案
* 整张表上方加一句提示：**不纠正孩子的选择——这是他们的表达，没有"正确"答案。如果孩子选了意想不到的词，好奇地问原因，而不是纠正。**

**教学引导撰写规则：**

* 英文脚本中标注互动动作（如「演示将 Word Bank 情绪词填入空格」「邀请孩子操作」）
* 核心信息反复强调："There's no wrong answer! This is YOUR song."

## 五、教学建议

**格式：** 表格，至少 4 条。

```markdown
| 情况 | 处理方式 |
|------|---------|
| 孩子不愿意开口 | 不强迫，鼓励用乐器参与；听几遍后自然会跟 |
| 孩子选了"奇怪"的词 | 不纠正，好奇追问原因，这是表达的机会 |
| 孩子跟不上节奏 | 切回 0.75x 或 0.5x，指着歌词逐句带 |
| 乐器声音太吵 | 约定"演奏信号"：引导师举手 = 全体停止 |
```

**撰写规则：**

* 每条覆盖一个常见课堂问题
* 处理方式写具体操作，不写"耐心引导""多加练习"等空话
* 至少包含：参与度问题、选择问题、节奏问题、纪律问题

## 七、设计原则速查

| **原则**  | **说明**                            |
| ------- | --------------------------------- |
| 无标准答案   | 填词没有"正确"选择，尊重每个孩子的表达              |
| 核心隐喻    | 每首歌有一个可反复引用的隐喻句，承载幸福力理念           |
| 感官锚定    | 主题元素必须与另一种感官配对（声音/动作/视觉），不止于词汇    |
| 变速脚手架   | 用 0.75x → 1x → 1.25x 递进，让每个孩子都能跟上 |
| 仪式感收尾   | 固定结束仪式（击掌/鼓掌/一句话分享），形成课堂记忆锚点      |
| 中英双语引导  | 每个环节配英文课堂脚本，中文标注操作要点和语气提示         |
| 15 分钟节奏 | 五步总时长控制在 15-25 分钟，环节二（创编）占比最高     |
