# 整曲页面联调

第二步「歌曲创作」的完整歌曲按钮改为一次提交全部歌词，不再逐句生成后拼接。

链路：页面 → `POST /api/creative-works/:id/music` → n8n `gene-music-full-song` → ComfyUI `/prompt` → `/history` 轮询 → 受保护 `/view` 下载 → 通用资源表 → `get-resource` → 同源鉴权下载 `GET /api/creative-works/:id/music?download=1` → 页面保存/播放。

页面每5秒查询作品自己的任务。刷新后重新打开第二步，点击生成按钮会复用同歌词的已有任务；失败任务可以重新提交。n8n API密钥和ComfyUI凭证留在服务端。

## 页面测试

1. 打开星光录音棚作品，进入第二步。点击「生成完整歌曲」或「重新生成完整歌曲」。
2. 等待任务完成，试听播放器中的整曲，检查全部歌词（含最后四句）是否被模型演唱。
3. 页面显示解码得到的实际音频时长。提示词要求约8秒前奏与4秒尾奏，但不保证模型严格遵循；不能据此推导真实歌词时间。
4. 新整曲生成后旧歌词范围、旧句片段、旧伴奏及听音题旧时间都会清除，避免把不相干的资源配到新歌。
5. 当前流程没有自动歌词对齐服务。可导入与实际音频对应的完整 `.lrc`，支持 `[00:08.125]`。必须与全部歌词逐行对应，包括重复句。结束时间取下一行开始时间，最后一行取实际音频结束时间；不是逐词/音素精确对齐。
6. 待对齐时可以听歌曲、设计题目，但暂不能生成授课课件，以免错误同步。真正自动对齐需要另接人声分离与强制对齐服务，并校验漏唱/重复句，不可用平均分配冒充。

当前不自动生成独立伴奏：ComfyUI流程只输出整曲。毫秒格式的显示能力不等于毫秒级声学准确度。
