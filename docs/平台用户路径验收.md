# 平台用户路径验收

2026 年 11 月 27 日至 28 日，使用教师和管理员都会用到的页面入口，在本地 5175 实际点击、输入、筛选、预览、退出和重新进入。正式后台的读取通过现有会话和数据库隧道完成。涉及创建、复制和修改的验收使用独立 PostgreSQL、项目实际 API 和正式库中已有的案例及课程副本。两种环境的验证范围分别列在下面。

## 外部依赖与验收范围

- 11 月 28 日上午复查了 n8n 正在运行的工作流。图片、分镜、配乐和配音使用 `117.50.47.150:8188`，视频片段使用 `117.50.199.231:8188`。n8n 健康检查成功，两台 GPU 的 ComfyUI 健康检查均超时。真实任务中，图片 `8594` 与分镜 `8596` 在 GPU 探测阶段失败。用已有的可访问课堂插图单独提交视频 `8597`，其片段子任务 `8601` 在向视频 GPU 上传首帧时超时。背景音乐 `8595` 与配音 `8598` 也连接超时。5175 的查询接口已回读这些失败，新媒体成品仍待 GPU 服务恢复后验收。
- 本轮绘本交互使用独立 PostgreSQL 中真实绘本的副本。正式库隧道需要重新认证，5175 再次读取绘本和瑜伽时均显示读取失败。右侧原有瑜伽课仍可浏览，保留原标签，等认证完成后再刷新。
- 新建、编辑和复制使用本机隔离数据库，数据库清理后不会出现在正式作品列表。5175 的正式业务写权限仍按既有授权执行。资源上传到正式 FTP、正式课程发布、删除真实账号或作品、教室实体摄像头及麦克风未作为验收动作。
- 回归包含前端交互测试、后端 TypeScript 检查和前端构建。课堂能打开和后台能接单分别记录，均不替代媒体成品验收。
