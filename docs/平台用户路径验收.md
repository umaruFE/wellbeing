# 平台用户路径验收

2026 年 11 月 27 日至 28 日，使用教师和管理员都会用到的页面入口，在本地 5175 实际点击、输入、筛选、预览、退出和重新进入。正式后台的读取通过现有会话和数据库隧道完成。涉及创建、复制和修改的验收使用独立 PostgreSQL、项目实际 API 和正式库中已有的案例及课程副本。两种环境的验证范围分别列在下面。

## 发现并修复的问题

| 实际操作与原现象 | 修改 | 复测结果 |

| 视频生成的“下一步”被 5175 拦截并返回 403。媒体任务失败后只显示笼统的操作失败 | 本地预览允许登录用户调用图片、分镜、视频、语音与音乐生成入口。轮询区分成功、运行、取消和失败，传递可读原因 | 5175 分镜与音乐请求均获后台受理。用实际失败的任务复查，分别返回 GPU 不可用和生成服务连接超时 |

## 用户路径覆盖

| 模块 | 实际操作与结果 |
| --- | --- |
| 登录、工作看板、任务中心 | 临时账号登录、退出、从直链重新登录。5175 切换最近课程、图片、视频、音频四个页签。任务中心从当前队列切到 99 条历史记录并关闭 |
| 艺术表达 | 案例库与个人作品切换，按书名搜索，检查 0 页和 8 页的授课条件，继续备课、返回，新建、填写核心词汇、保存。宿主浏览器拦截了独立授课窗口，窗口内的翻页未作人工验收 |
| 歌曲编唱屋 | 从《唱出今天的心情》预览进入课堂，选择第一处填空、填入 happy，切换到演唱模式并返回。独立库进入新建模板选择、复制案例、同步后台后在自己的作品中查到草稿 |
| 星光音乐棚 | 按旋律舞者筛选，打开《阳光律动》的详情、预览，从第 1 句走到第 2 句再返回。独立库新建活动、制作同款并在个人作品中读回 |

## 外部依赖与验收范围

- n8n 接收了真实请求。图片任务在 GPU 存活检查失败，视频在分镜生成阶段遇到相同故障，背景音乐和英语配音在请求生成服务时连接超时。图片/音频和视频两台指定主机的 8188 端口从本机探测均超时。此次未得到可播放的新视频、音乐或新生成图片，后续成品验收需要 GPU 服务恢复。
- 新建、编辑和复制使用本机隔离数据库，数据库清理后不会出现在正式作品列表。5175 的正式业务写权限仍按既有授权执行。资源上传到正式 FTP、正式课程发布、删除真实账号或作品、教室实体摄像头及麦克风未作为验收动作。
- 回归包含前端交互测试、后端 TypeScript 检查和前端构建。课堂能打开和后台能接单分别记录，均不替代媒体成品验收。
