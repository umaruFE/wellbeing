## 一、本次完成的改动（按时间线）

### 1. 授课模式全面改为「新窗口 + Blob URL」
- 新增 `src/utils/teachingWindow.js`：
  - `openTeachingWindow({ pages, title, backgroundMusic })` —— 瑜伽/绘本共用的纸质风翻页窗口（←/→ 翻页、Esc 退出、背景音乐播放/音量）。
  - `openSongWindow({ draft, blankValues, arrangement, audio, backgroundUrl })` —— 歌曲编唱屋授课窗口（四色歌词卡、填词、逐行乐器 chip、播放器带 0.5–1.5× 变速与原唱/伴奏切换）。背景用 CDN 图 918 + 68% 白纱遮罩。

- **删除了所有独立 HTML 打开/下载后端路由**（`api/src/app/api/creative-works/[id]/html/route.ts` 已删）；`render/route.ts` 把 html 内容直接放在 JSON 响应里返回，前端 `URL.createObjectURL` 转 Blob URL。列表弹窗防拦截：先 `window.open('')` 再回填 `location.href`（`presentFromList`）。

### 3. 星光录音棚制作流程改为 7 步（与授课四关一一对应）
- `STEPS = 基本信息 → 歌曲创作 → 第一~四关（练习+教案）→ 音频与课件`；`STAGE_STEPS = {1:2,2:3,3:4,4:5}`、`AUDIO_STEP = 6`。
- 第一关（Lyric Hunter）：选词填空 + 连词成句 + 听音选词（游戏里第一关含全部三类挑战）+ 第 1 关教案。

- 第三关（Echo Master）：EchoMasterPreview 组件——三档难度预览（Beginner/Intermediate/Challenge）+ 逐行分段音频试听 + **逐行挖词编辑**（中级整词隐藏 / 高级首字母，echoData.intermediate/challenge，词来自该行原文，逗号分隔，可只挖单个词）+ AI 按 section=`echoData` 生成；后端 normalizeEchoData 按歌词行对齐后注入模板 `var echoData`，游戏 getMaskedText 据此遮挡。
- 第四关（Star Studio）：Stage Star 颜色分工编辑器 + 第 4 关教案。
- `PlansEditor` 支持 `stage` prop（单关模式不显示页签）；`saveExercises(nextStep)` 参数化。
- 步骤条固定两行（4+3），样式在 `creativeWorkshop.css` 的 `.cw-steps-seven` / `.cw-steps-row`。
