# 瑜伽角色动作动画 · 2026-11-19

## 已实现

用户要求为当前蓝色角色制作瑜伽动画。本轮在新版 Wellbeing 的 A Walk in Wonder 内接入 8 组基于原透明 PNG 的实时 2D 纹理网格动画，包含上举、树式平衡、侧伸展、站立平衡、坐姿轻转、向上伸展、蝴蝶膝盖开合和休息呼吸。

`wonder-motion.js` 保存每组关节、影响区、面部保护与固定支撑点，提供准备、伸展、停留、还原四阶段纯进度采样。每帧 525 顶点、960 三角形。`wonder-motion-renderer.js` 按原角色裁切上传 WebGL 纹理，用单次 draw 调用绘制当前姿态；未另建播放定时器。原背景、角色 PNG、故事英文与教师动作名称保留，课堂动作标题继续隐藏。

- 课堂或案例预览：进入动作页，点击「播放本页」，动作与现有英语朗读进度同步；暂停/继续沿用原播放器。
- 教师备课：内容编排的「播放动作」提供约 10 秒无音频示范，可停止、重播。
- 整课配乐预览：复用原进度与翻页流程；切页不遗留独立动画循环。
- 模块隐藏或离开时沿用原停止逻辑，返回不会自动开始播放。图片异步加载后只绘制最近请求的进度。
- 减少动态偏好显示固定目标姿势，朗读和进度仍可使用。图形初始化失败或上下文丢失保留原图并提示；移除角色页面时释放图形资源。

此次动画是对原姿态局部关节与呼吸的 2D 演示，不生成新的图片、视频或音频。未改课程模型、草稿、授课版、角色原图或旧六页课程渲染；旧课程继续用原动作示范。

维护源：`source/wellbeing-20261118/workbench-ui/yoga/`。新增 `wonder-motion.js`、`wonder-motion-renderer.js`；修改 `wonder-scene.js/css`、`app.js` 的动作入口及播放时长；打包器登记新脚本与哈希。

入口：`http://127.0.0.1:5198/workshop/interactive-yoga`，刷新页面后查看。

## 图形检查的边界

`mesh-contact-sheet.png` 为最终运动采样在原背景中的离线栅格化对照，5 阶段 × 8 姿态。已查看并据首轮结果增加动作幅度，再检查最终角色变形与背景落点。该图使用相同顶点/UV/原 PNG 验证几何，不复现完整 UI、瑜伽垫与精确字幕排版，**不是浏览器截图**。

CUA 获取当前预览标签页再次超时并重置，因此未验证真实 GPU 的最终像素、连续播放观感、帧率、设备语音或投屏。自动测试使用 DOM/WebGL doubles，不能替代真实浏览器验收。课堂动画进度沿用既有语音时长估算，参考动作提供独立固定时长演示。
