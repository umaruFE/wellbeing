# 儿童与健康教育标准

> 全产线共用的教育理论基础：4E 教学法、SEL 与 PERMA 双目标、年龄段适配、核心指标。所有课程、绘本、歌曲、课件、游戏的教育设计必须以本页为准。

## 1. 教育理念总纲

**双目标并轨**：每份内容同时承载、且不可互相替代——

1. **英文目标**：可观测的具体语言行为（认读、说出、填入、跟唱）
2. **幸福力目标**：SEL + PERMA 维度下的体验与认知转变

**三条铁律**：

- 目标必须可观测，禁止写「掌握」「了解」等模糊词
- 幸福力目标用一句可引用的核心隐喻收尾（如「情绪像天空一样变化，每一种都值得被听见」）
- 产出物是可见可听的成果（一幅作品、一首歌、一次展示），不是抽象的「学会」

## 2. 4E 教学法（核心课堂结构）

所有课程、教案、课件的环节组织均遵循四阶段：

| 阶段 | 名称 | 功能 | 时间占比参考 |
|------|------|------|-------------|
| E1 | Engage 引入 | 情境钩子、激活背景知识、建立情感连接 | ~20% |
| E2 | Empower 赋能 | 提供语言与思维支架（词汇、句型、示范） | ~25% |
| E3 | Execute 实践 | 学生动手做（创作、游戏、演唱、运动） | ~40% |
| E4 | Elevate 升华 | 展示、分享、情感收束、核心隐喻回扣 | ~15% |

对应平台「教案设计」模块的四阶段视图；课件大纲亦按四阶段折叠树组织。

**阶段内必填字段**：语言目标、SEL 焦点、PERMA 焦点、阶段叙事。超时（超出课程总时长配置）系统会警告。

## 3. SEL 五维度

社会情绪学习（CASEL 框架），内容设计时标注所属焦点：

| 维度 | 定义 | 内容示例 |
|------|------|---------|
| Self-Awareness 自我认知 | 识别并命名自己的情绪、喜好、特长 | 情绪词汇绘本、My Emo Friend |
| Self-Management 自我管理 | 调节情绪、呼吸、延迟满足 | 冥想引导音频（C6）、瑜伽收束 |
| Social Awareness 社会认知 | 共情他人、识别他人感受 | A Seat for You（空椅子与邀请） |
| Relationship Skills 人际技能 | 合作、分享、沟通 | 多人游戏、小组创编 |
| Responsible Decision-Making 负责任决策 | 后果思考、善意选择 | 情境选择类故事 |

## 4. PERMA 幸福模型

积极心理学五要素，用于标注每阶段/每环节的幸福力焦点：

| 要素 | 含义 | 课堂载体 |
|------|------|---------|
| P 积极情绪 Positive Emotion | 愉悦、惊喜、感恩 | 随机机制的惊喜揭晓、仪式感收尾 |
| E 投入 Engagement | 心流、专注 | 创作环节（15-20 min 沉浸） |
| R 关系 Relationships | 积极连接 | 配对练习、合唱、击掌仪式 |
| M 意义 Meaning | 超越自我的价值 | 照顾角色/他人的任务驱动（"Can we make one for them?"） |
| A 成就 Accomplishment | 完成与掌控 | 作品上墙、完整演出、再来一遍 |

## 5. 年龄段适配标准

平台三个年龄段（3-6 / 7-9 / 9-12 岁），内容参数随年龄段调整：

| 维度 | 3-6 岁 | 7-9 岁 | 9-12 岁 |
|------|--------|--------|---------|
| 单句长度 | ≤ 8 词 | ≤ 10 词 | ≤ 12 词 |
| 每页/每屏词量 | ≤ 20 词 | ≤ 35 词 | ≤ 50 词 |
| 创作环节时长 | 15 min（高辅助） | 15-20 min | 12-15 min（高自主） |
| 语言支架 | 完整句型跟读 | 句型框架提示 | 开放式描述 |
| 随机机制 | 老师主导揭晓 | 孩子轮流揭晓 | 孩子自主揭晓 |
| 材料选择 | 老师预设 2-3 种 | 4-5 种自选 | 自由选择 |
| 对话模式 | 全班齐读 + 配对 | 配对 + 展示 | 小组讨论 + 展示 |

班级人数档位：≤ 8 人 / 9-15 人 / ≥ 16 人（影响分组策略与乐器分配）。

## 6. 语言目标标准

### 6.1 词汇

- 每节课核心词汇 6-10 个，全部来自课程创建时录入的「核心词汇」标签
- 词汇必须在内容中**全覆盖**：正文、对话气泡或 Word Bank 至少出现一次
- Word Bank 规模 = 填空数 + 2-3 个干扰词（歌曲场景）

### 6.2 句型

- 每节课核心句型 1-3 个；同一句型在同一内容中避免机械重复（用不同词汇覆盖）
- 句型需在「语言输出」环节集中练习，配黑板/投影支架：

```
What is there?
→ There is a ________ and a ________.
Where is the ________?
→ It's next to / near / in the ________.
```

### 6.3 纠错原则

- 不打断流利表达；用自然复述纠正（孩子："a lake and mountain" → 老师："Yes! a lake and a mountain!"）
- 严重错误课后单独处理
- 孩子说中文时不纠正，自然带出英文（"Ah，山！Yes, a mountain! Can you say mountain?"）

## 7. 核心创作原则（全产线通用）

| 原则 | 说明 |
|------|------|
| 无标准答案 | 填词、创作没有「正确」选择；孩子选了意想不到的词，好奇追问而非纠正 |
| 核心隐喻 | 每份内容有一个可反复引用的隐喻句，收尾必须引用原文，不额外发挥 |
| 感官锚定 | 抽象概念必须与另一种感官配对（情绪→乐器、词汇→动作、颜色→声音） |
| 随机机制 | 创作类内容用掷骰子/抽盲袋/转盘/翻牌制造个性化与悬念 |
| 变速脚手架 | 音频/演唱类内容提供 0.75x → 1x → 1.25x 递进 |
| 仪式感收尾 | 固定结束仪式（击掌/鼓掌/彩虹手势/作品上墙），形成记忆锚点 |
| 中英双语引导 | 教案话术为完整可念英文 + 中文操作要点与语气标注 |
| 用「我们」不用「你们」 | 角色代入与共同体验 |

## 8. 身心调节理论（体感/瑜伽/冥想内容适用）

- **呼吸练习**：儿童腹式呼吸引导，4 秒吸气 - 2 秒停 - 6 秒呼气起步；单次练习 ≤ 3 分钟
- **身体扫描**：从脚到头逐部位命名，语言与当时课程的身体词汇联动
- **安全第一**：所有体感动作见 [瑜伽动作规范](/wellbeing/yoga/action-standard)，禁止对儿童脊柱、颈部施压的体式
- **示范而非纠正**：视频/动画示范标准动作，教师口头引导，不强行按压儿童身体

## 9. 内容审核红线

- [ ] 无暴力、恐怖、歧视、暗示性内容
- [ ] 无「标准答案式」评价语（wrong / stupid / fail 等禁止出现）
- [ ] 无超龄语言与超纲情绪词
- [ ] 幸福力隐喻积极、不说教
- [ ] 涉及家庭/文化元素保持中性、多元
