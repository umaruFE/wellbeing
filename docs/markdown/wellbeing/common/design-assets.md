# 视觉风格与设计规范

> 全产线通用的视觉标准：色彩体系、字体、插画风格、画幅比例、资产命名与导出规范。所有图片/课件/视频/游戏产出必须遵循本页标准。

## 1. 设计原则

1. **儿童优先**：高明度、中低饱和的安全色，形状圆润，无尖锐棱角与恐怖元素
2. **一致性**：同一课程/绘本/视频内画风、色板、角色形象严格一致
3. **可读性**：正文与背景对比度 ≥ 4.5:1；文字区域预留纯色/低噪底
4. **可生成性**：所有视觉资产均可通过 AI（ComfyUI）按本规范 Prompt 模板复现

## 2. 色彩体系（Design Tokens）

设计令牌（Design Tokens）源文件位于前端仓库 `src/theme/design-tokens/`，由 Figma Variables 导出，分 Light / Dark 两套主题与 Compact / Default 两套尺寸。

### 2.1 基础色

| Token | 值 | 用途 |
|-------|-----|------|
| colorBgBase | `#FFFFFF` | 页面底色 |
| colorTextBase | `#000000` | 文字基色 |
| colorText-1 | `#333E4E` | 正文主色（深蓝灰） |
| colorWhite | `#FFFFFF` | 固定白（不随主题切换） |
| transparent | 透明 | 占位/遮罩 |

### 2.2 IP 角色标准色（品牌色板）

五个 IP 角色各绑定一个识别色，任何场景不得混用或改色：

| 角色 | 标准色 | HEX |
|------|--------|-----|
| Poppy | 粉色 | `#FFB6C1` |
| Edi | 蓝色 | `#87CEEB` |
| Rolly | 橘色 | `#FFA500` |
| Milo | 黄色 | `#FFD700` |
| Ace | 紫色 | `#9370DB` |

用途：角色出现时的强调色、课件章节色、游戏 UI 主题色、统计图表配色。

### 2.3 课件主题色

课件提供三套主题模板（详见 [课件标准模板](/wellbeing/courseware/template)）：

| 模板 | primary | secondary | accent |
|------|---------|-----------|--------|
| 红色商务风 | `#B91C1C` | `#DC2626` | `#EF4444` |
| 蓝色商务风 | `#1E40AF` | `#2563EB` | `#3B82F6` |
| 自然商务风 | `#166534` | `#16A34A` | `#22C55E` |

## 3. 字体规范

| 层级 | 字号（画布 960×540） | 字重 | 用途 |
|------|----------------------|------|------|
| 封面标题 | 32px | Bold | 课件封面 |
| 页标题 | 20px | Bold | 内容页标题 |
| 目标/正文 | 13px | Normal | 语言目标、活动概述 |
| 活动步骤 | 12px | Normal | 分步骤正文 |
| 教师脚本 | 11px | Normal | 辅助说明（灰色 `#6B7280`） |

- 中文优先使用系统默认无衬线字体；英文教学内容使用无衬线字体（类 Inter/Segoe UI）
- 幼儿段（3-6 岁）素材文字不小于 16px，单词卡配图占版面 ≥ 60%
- 行高 1.4-1.6；文字层级不超过 3 级

## 4. 插画风格库

平台内置 5 种标准画风（`public/ppt/style-previews/`），生成图片时必须从中选择：

| 风格 ID | 名称 | 适用场景 |
|---------|------|---------|
| cartoon-illustration | 卡通插画 | 默认通用，IP 角色场景 |
| watercolor-storybook | 水彩绘本 | 绘本、情感类主题 |
| crayon-collage | 蜡笔拼贴 | 艺术表达类课程、儿童创作氛围 |
| clay-3d | 3D 黏土 | 立体化场景、游戏素材 |
| realistic-photography | 写实摄影 | 自然探索、真实世界认知 |

**一致性规则**：同一绘本/课件/视频内的所有页面使用同一种画风；画风在生成 Prompt 中作为固定前缀写入。

## 5. 画幅与分辨率

| 比例 | 尺寸（px） | 用途 |
|------|-----------|------|
| 16:9 | 1920×1080 | 课件、视频、横幅 |
| 4:3 | 1024×768 | 标准横版插图 |
| 1:1 | 1024×1024 | 闪卡、图标、社交图 |
| 3:4 | 768×1024 | 绘本页、标准竖版 |
| 9:16 | 1080×1920 | 竖版视频、移动端 |

课件画布统一 **960×540（16:9）**；导出视频统一 1080p。

| B2 | 带文字场景图 | 场景 + 标题文字 |

| B5 | 活动氛围图 | 活动环节背景 |

## 7. 资产命名规范

```
{模块}-{类型}-{主题或课程ID}-{序号}-{版本}.{ext}

示例：
book-B9-nature-unit3-P04-v2.png      绘本第 4 页插画 v2
ppt-B3-animals-flash-01.png          词汇闪卡第 1 张
yoga-V1-mountain-01.mp4              瑜伽动作视频
music-C5-happy-song-v1.mp3           主题歌曲
```

- 全部小写，单词间用连字符 `-`，禁止空格与中文（主题词可用拼音）
- 版本号 `v1/v2/...`，重生成必须递增版本而非覆盖
- 上传素材库时自动读取尺寸，需补充来源标签（AI / 手动 / 课程）

## 8. 导出与交付规范

| 资产 | 格式 | 附加要求 |
|------|------|---------|
| 插画/闪卡 | PNG | 透明背景资产需先去背景（remove.bg / 本地 sharp 白底去除） |
| 课件 | .pptx | 使用 pptxgenjs 本地导出，字体转基础样式 |
| 视频 | MP4 (H.264) | 1080p，帧率 30fps，见动画流水线规范 |
| 音频 | MP3 | 44.1kHz，见音频资源库规范 |
| 印刷（绘本成品） | PDF | 300dpi，CMYK 校色后输出 |

## 9. 审核清单（视觉）

- [ ] 画风与该课程/绘本登记画风一致
- [ ] IP 角色配色、比例、形象无变形（对照角色设定页）
- [ ] 文字可读、无错别字、无占位符残留
- [ ] 无版权风险元素（真实商标、明星脸、水印）
- [ ] 儿童安全：无暴力、恐怖、暗示性内容
- [ ] 命名符合第 7 节规范并已入库打标
