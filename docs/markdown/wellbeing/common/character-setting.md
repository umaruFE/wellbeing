## 2. 世界观与故事背景

### 2.1 世界观：Wellbeing 小镇

五个角色生活在一座被森林、湖泊和星光环绕的小镇——**Wellbeing 小镇**。小镇的中心是「成长罗盘」，它指向每个人内心的四种力量：**表达（Express）、探索（Explore）、连接（Connect）、平静（Calm）**。

- 每集故事围绕一个小镇日常事件展开（迷路的小鸟、新邻居、下雨天的运动会）
- 角色们通过 4E 旅程（Engage→Empower→Execute→Elevate）解决问题
- 故事永远回到孩子身上：角色的经历是孩子情绪与成长的镜像

### 2.2 角色与教育目标的映射

角色不是装饰，而是教学功能的载体。选用角色时按教育目标匹配：

| 教学场景 | 首选角色 | 理由 |
|---------|---------|------|
| 情绪认知 / 共情类 | Poppy | 共情担当，示范「说出感受」 |
| 科学探索 / 自然主题 | Edi | 好奇发问，示范「观察与假设」 |
| 体感 / 运动 / 瑜伽 | Rolly | 活力担当，示范「身体参与」 |
| 音乐律动 / 歌曲编唱 | Milo | 节奏担当，示范「大胆表达」 |
| 冥想 / 呼吸 / 收尾静心 | Ace | 沉静担当，示范「回到内心」 |

## 3. 形象一致性规范（硬约束）

1. **识别色不可更改**：角色主色固定（见总表），不得换色、不得使用他人识别色
2. **比例标准**：Q 版三头身；头部占身高 1/3；四肢圆润无锐角
3. **五官简化**：豆形眼 + 简单嘴型；不画鼻子细节；表情靠眼睛与嘴形变化
4. **三视图基准**：正式产出前需有正面/侧面/背面三视图（`{role}-turnaround-v{n}.png`）
5. **表情库**：每角色至少 9 个标准表情（喜/怒/哀/惧/惊/厌/平静/好奇/困倦）
6. **动作库**：每角色至少 12 个标准动作（站/坐/走/跑/跳/举手/拥抱/指认/拍手/鞠躬/躺/伸展），供 B11 类资产与视频动捕参考
7. **AI 生成**：使用平台「IP 角色动作图（B11）」生成，Prompt 中必须包含角色 ID、识别色与画风，保持跨页一致

### 3.1 多人场景规范（B13 / IP 场景合成）

- 同框角色 ≤ 3 个（视频三人版工作流上限）
- 主角色占画面视觉重心，配角错落排布，避免对称呆板
- 角色间距 ≥ 0.5 个头身，防止遮挡识别色
- 背景遵循当前课程画风，不得喧宾夺主

## 5. 使用规范

### 5.1 允许

- 在绘本、课件、视频、游戏中以标准形象出现
- 按教育目标映射表选择角色
- 使用角色识别色作为该内容模块的强调色

### 5.2 禁止

- 修改识别色、五官比例、体型
- 让角色做出暴力、危险、恐怖行为
- 角色说教式长篇台词（角色语言必须短句、口语、可跟读）
- 将角色用于课程内容之外的商业物料（需单独审批）

### 5.3 台词写作规范

- 单句 ≤ 12 词（与绘本规范一致）
- 角色之间对话用气泡（`💬`）呈现，一页最多 3 组
- 角色永远「示范」而非「命令」：用 "Let's try!" 不用 "You must..."
- 情绪命名遵循课程目标词汇，不引入超纲情绪词
