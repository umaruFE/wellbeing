# 游戏逻辑与数值说明

> 小游戏的胜负判定、计分公式、难度数值、状态机与代码结构标准。与 [游戏策划案 GDD](/wellbeing/games/game-design-doc) 配套使用。

## 1. 胜负与结束判定

| 游戏类型 | 判定规则 |
|---------|---------|
| Bingo | 划格连成一线（横/竖/斜）即达成；全班模式多线庆祝 |
| 猜单词 | 揭示字母数达上限前猜出即胜；达上限显示答案 + "Try a new one!" |
| 配对类（闪卡/情绪配对） | 全部配对完成即胜，无失败态；步数仅作记录展示 |
| 排序类（拼图阅读） | 全部落位正确即胜；错位弹回并可重试（不限次） |
| 抢答类 | 计时结束按得分结算；无「输家」画面，最低分也给参与星 |
| 开放类（盲袋/表演） | 完成即胜利，不判定对错 |

**统一规则**：

- 所有游戏都有「结束」没有「失败」：结算页永远展示获得项（星星/彩虹/角色击掌）
- 重试无限次；连错 2 次触发保底（见第 3.4 节）
- 单局硬超时 = 环节时长上限（默认 5 min），到时自动进入结算

## 2. 计分公式（标准）

```
基础分：答对 1 题 = 10 分
连击加成：连续答对第 n 题额外 + (n-1) × 2，上限 +10
速度加成：限时题在剩余时间 > 50% 时答对额外 +5
小组加成：小组模式全组完成保底题，每人 +5（鼓励协作非竞争）
```

```
总分 = Σ(基础 + 加成) ，星级映射：
★ = 完成全部关卡（保底也计入）
★★ = 总分 ≥ 完成分 × 1.2
★★★ = 总分 ≥ 完成分 × 1.5 或零提示通关
```

**禁止**：排行榜展示末位姓名、扣分机制、与同学公开对比分数。

## 3. 数值平衡标准

### 3.1 干扰项（选项数）

| 关卡 | 干扰项 | 说明 |
|------|--------|------|
| 第 1 关 | 2 | 新词首教，几乎必对 |
| 第 2-3 关 | 3 | 建立辨析 |
| 第 4-5 关 | 4 | 上限，不再增加 |

干扰项选取规则：同词性、同主题、音节相近优先；禁用形近到无法辨认的干扰。

### 3.2 时间参数

| 项目 | 3-6 岁 | 7-9 岁 | 9-12 岁 |
|------|--------|--------|---------|
| 单题时限 | 无限制 | 20s | 12s |
| 单关时长 | 60-90s | 45-75s | 45-60s |
| 反馈动效停留 | 1.5s | 1s | 0.8s |

### 3.3 难度曲线

```
难度 D(k) = 0.4 × 干扰项因子 + 0.3 × 时间因子 + 0.3 × 新词因子
相邻关卡难度增量 ≤ 0.15，保证平滑
```

### 3.4 保底机制（动态难度）

- 连错 2 次 → 干扰项减 1、移除时限、给出提示（首字母/图片线索）
- 保底通关仍获得 ★（完成即胜利），只是不加速度分
- 触发保底不打标签、不播报，静默降难（保护自尊）

## 4. 状态机（统一游戏生命周期）

```
            ┌─────────┐
   start ──▶│ INTRO   │ 规则演示（IP 角色示范一遍）
            └────┬────┘
                 ▼
            ┌─────────┐  next   ┌─────────┐
            │ PLAYING │───────▶ │ LEVEL_UP│
            └────┬────┘◀───────└────┬────┘
        pause │  │ timeout/win       │ last
              ▼  ▼                   ▼
        ┌───────┐ ┌───────────────────┐
        │PAUSED │ │      SETTLE       │ 结算：星星 + 仪式动效
        └───┬───┘ └────────┬──────────┘
            │ resume       ▼
            └────────▶  END（击掌/彩虹手势收尾）
```

规则：

- INTRO 可跳过（老师控制），跳过不惩罚
- PAUSED 由教师触发（课堂管控），恢复后倒计时 3-2-1
- SETTLE 后固定播放结束仪式（对齐教育标准「仪式感收尾」）
- 状态转移全部留痕（埋点，见第 6 节）

## 5. 代码结构标准

### 5.1 模块划分

```
src/modules/games/
├── {game-id}/
│   ├── {Game}Page.jsx          # 容器：状态机 + 生命周期
│   ├── {Game}Board.jsx         # 棋盘/玩法纯展示组件
│   ├── {Game}Settle.jsx        # 结算仪式
│   ├── useGameEngine.js        # 核心逻辑 Hook（判定/计分/难度）
│   ├── gameConfig.js           # 数值配置（对应 GDD 第 6 节）
│   └── index.js
└── shared/                     # 共享：计分器、计时器、反馈动效、音效管理
```

### 5.2 配置与逻辑分离

所有第 2-3 节数值收敛在 `gameConfig.js`，禁止硬编码在组件内；调平衡只改配置发版。

### 5.3 游戏数据结构（题目 JSON Schema）

```json
{
  "gameId": "flash-flip",
  "ageBand": "7-9",
  "languageGoal": { "words": ["lake", "mountain"], "patterns": ["There is a ..."] },
  "levels": [
    {
      "id": 1,
      "distractors": 2,
      "timeLimitSec": null,
      "items": [
        {
          "type": "word-image",
          "word": "lake",
          "image": "ppt-B3-nature-lake-01.png",
          "audio": "ppt-C3-lake-v1.mp3",
          "hint": "It's blue and quiet."
        }
      ]
    }
  ],
  "rewards": { "starThresholds": [1.0, 1.2, 1.5] },
  "ipRole": "rolly",
  "feedbackPack": "standard-warm"
}
```

题目数据来自课程核心词汇，可由 AI 按课程批量生成后人工审校。

## 6. 埋点与数据

| 事件 | 字段 |
|------|------|
| game_start | gameId、courseId、ageBand |
| level_start / level_end | levelId、用时、正确率 |
| answer | itemId、正误、用时、是否保底态 |
| game_settle | 总分、星级、完成率 |
| teacher_pause | 时长 |

数据用途：验证难度曲线假设（目标各关正确率 0.85 / 0.75 / 0.70），异常即回调数值。

## 7. 性能与容错

- 交互响应 ≤ 100ms；动效不得阻塞输入（CSS transform/opacity 优先）
- 音效加载失败静默降级（游戏可玩），控制台告警
- 断线/刷新：进度写入 localStorage，恢复从当前关重开（不保留题内进度）
- 防连点：答题类交互 300ms 节流（对齐[交互规范](/wellbeing/courseware/interactivity-spec)）

## 8. 验收清单

- [ ] 判定规则与 GDD 一致，开放类无对错判定
- [ ] 结算页无失败态、无末位展示
- [ ] 保底机制静默触发且生效
- [ ] 数值全部在 gameConfig，难度增量 ≤ 0.15
- [ ] 时间参数匹配年龄段表
- [ ] 状态机覆盖 INTRO/PLAYING/PAUSED/SETTLE/END，教师可暂停
- [ ] 埋点齐全，正确率可回收
- [ ] 题目 JSON 符合 Schema 且经人工审校
