# 游戏策划案 (GDD)

> 课堂互动小游戏的标准策划文档：游戏类型库、核心玩法循环、关卡设计、GDD 模板与评审标准。游戏服务于 4E 课堂中的 Execute（实践）环节。

## 1. 定位与设计原则

小游戏是**课堂环节**，不是独立产品：

| 原则 | 说明 |
|------|------|
| 5 分钟一局 | 单局 3-5 分钟，匹配课堂环节时长 |
| 语言目标优先 | 玩法服务于词汇/句型操练，娱乐是载体不是目的 |
| 无失败羞辱 | 遵循「无标准答案」原则，失败反馈温和（见[交互规范 3.2](/wellbeing/courseware/interactivity-spec)） |
| 全员参与 | 支持 ≤ 8 / 9-15 / ≥ 16 三档班级规模的分组策略 |
| IP 角色陪伴 | 角色做示范与鼓励，不做裁判 |

## 2. 游戏类型库

平台「经典活动」库对应的游戏类型（与课件交互模板一一对应）：

| 类型 | 玩法核心 | 语言目标匹配 | 人数 |
|------|---------|-------------|------|
| Bingo | 听词划格，连线庆祝 | 词汇听辨 | 全班/个人 |
| 猜单词 | 逐字母揭示猜词 | 词汇拼写 | 小组抢答 |
| 情景对话 | 角色对话推进剧情 | 句型运用 | 配对 |
| 闪卡翻转 | 翻卡配对（图-词） | 词汇认读 | 个人/配对 |
| 拼图阅读 | 段落排序成文 | 阅读逻辑 | 小组 |
| 我画你猜 | 画图猜词 | 词汇表达 | 全班 |
| 节奏拍拍 | 听音按节奏点击（配 C2） | 词句跟唱 | 全班 |
| 情绪配对 | 情绪词 ↔ 表情/乐器音色配对（SEL） | 情绪词汇 + 共情 | 个人/配对 |
| 身体拼拼 | 跟随 IP 角色做动作（配 V1 视频） | 身体词汇 + TPR | 全班 |
| 盲袋惊喜 | 数字盲袋/转盘随机揭晓（绘本机制游戏化） | 任意词汇 | 全班 |

## 3. 核心玩法循环

所有游戏遵循统一微循环：

```
出题（目标语言点）→ 玩家操作（选择/拖拽/点击/表演）
→ 即时反馈（正确庆祝 / 温和重试 / 开放接纳）
→ 奖励推进（星星/彩虹/角色欢呼）
→ 难度递增 → 循环 3-5 轮 → 结算仪式（击掌/彩虹手势）
```

## 4. GDD 文档模板（复制即用）

```markdown
# {游戏名} GDD · v{N}

## 1. 概述
- 一句话定位：
- 类型：（类型库中选）
- 适用年龄 / 班级人数档：
- 单局时长：X-Y min
- 语言目标：词汇 / 句型
- 幸福力目标：SEL 维度 + PERMA 要素
- 使用阶段：Engage / Empower / Execute / Elevate

## 2. 玩法规则
- 核心循环图/描述
- 操作方式（点击/拖拽/语音/肢体）
- 胜利条件 / 结束条件（开放类写「完成即胜利」）
- 计分规则（引用 logic-spec 标准公式）

## 3. 关卡/难度设计
| 关卡 | 目标语言点 | 干扰项 | 时间压力 | 难度曲线 |
- 难度递进参数引用 logic-spec 第 3 节

## 4. 界面与资产
- 画面布局示意（960×540）
- 出场 IP 角色与用途（示范/鼓励/反派禁止）
- 素材清单：B 类图片 / C 类音频 / V 类视频

## 5. 反馈与音效
- 正确/重试/开放反馈（对齐交互规范 3.2）
- 音效清单（引用音频资源库）

## 6. 数值与判定
- 引用 logic-spec 章节或内嵌判定表

## 7. 教师脚本
- 开始引导语 / 过程提示语 / 结束仪式语（完整英文短句）

## 8. 状态
- 草稿 / 已评审 / 已开发 / 已发布
```

## 5. 关卡设计标准

| 项目 | 标准 |
|------|------|
| 关卡数 | 每局 3-5 关，单关 45-90 秒 |
| 难度曲线 | 平滑递增：干扰项 2 → 4；时间压力无 → 有（仅 L2+） |
| 新词引入 | 新词只出现在关卡首题，并先出示范（闪卡/音频 C3） |
| 复习嵌入 | 每关最后一题回滚到首关语言点（间隔复习） |
| 保底体验 | 连错 2 次自动降低干扰项并给出提示，保证完成感（PERMA-A） |

## 6. IP 角色使用

- 鼓励者：答对时角色欢呼动效 + 台词（"You found it!"）
- 示范者：首关由角色演示一遍操作
- 伙伴：多人游戏角色分配到各小组做「队徽」（用识别色区分，见[角色设定](/wellbeing/common/character-setting)）
- 禁止：角色做反派、嘲讽表情、惩罚性行为

## 7. 评审标准（GDD 评审会检查项）

- [ ] 类型库内有对应交互模板，或已注明新交互的开发需求
- [ ] 语言目标明确且全部来自课程核心词汇/句型
- [ ] 幸福力目标标注 SEL + PERMA 维度
- [ ] 单局 ≤ 5 分钟，3 档班级人数均有分组方案
- [ ] 难度曲线符合第 5 节，含保底机制
- [ ] 反馈与音效符合交互规范与音频规范，无羞辱性反馈
- [ ] 素材清单完整且可由 AI 生成（B/C/V 类编号）
- [ ] 教师脚本完整英文可照念
- [ ] 数值判定引用或符合 [游戏逻辑与数值说明](/wellbeing/games/logic-spec)
