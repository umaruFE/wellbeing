# 互动式情境瑜伽内容与教案规范

> 所属路径：“英语+”融合活动 → 体感探索。核心方法是“情境驱动身体动作，身体动作内化语言”。

## 0. 输入参数表单（2026-09-07 更新）

工作室第一步“基本信息”的参数定义（前端 `YogaStudioPage.jsx` 与生成提示词共用）：

| 参数 | 必填 | 形式 | 取值 |
|------|------|------|------|
| 目标语言 | 是 | 自由输入 | 目标词汇与句型（如 ocean, wave, What can you see?） |
| 年龄段 | 否 | 单选 | 3-6岁 / 7-9岁 / 10-12岁 / 13-15岁 |
| 时长范围 | 否 | 单选 | 3-5分钟 / 5-8分钟 / 9-15分钟 |
| 情境主题 | 否 | 多选 | 自然探索（森林、海洋、花园……）/ 动物世界（丛林动物、海洋生物……）/ 日常生活（整理房间、烹饪食物……）/ 太空冒险（星球旅行、宇航员训练……）/ 魔法幻想（魔法学校、精灵世界……）/ 季节旅行（春夏秋冬场景变换） |
| 道具偏好 | 否 | 多选 | 无道具（纯身体练习）/ 基础瑜伽道具（瑜伽垫、瑜伽球、瑜伽砖、泡沫轴）/ 体适能道具（平衡木、跷跷板、过河石、弹力带、跳箱、蹦床、小哑铃、弹力绳）；未选默认无道具 |
| 特殊要求 | 否 | 自由输入 | 角色、体式偏好等补充说明 |

多选项在保存时合并为顿号分隔字符串（`theme`、`props`），生成时注入提示词：动作设计优先使用所选道具；选“无道具”时全部使用纯身体练习，不得要求任何器材。页数建议随新时长：3-5分钟约 6 页，5-8分钟约 8 页，9-15分钟约 10-12 页。

## 1. 活动定义

教师同时扮演探险向导与瑜伽教练，引导学生通过连续情境、身体动作和目标语言完成沉浸式活动。字幕是情境邀请，不是体式指令；场景先行，动作是身体对情境的自然回应。

## 2. 结构约束

| 项目 | 标准 |
|------|------|
| 总页数 | 6–12 页 |
| 页面结构 | 场景页 1 + 过渡页 1 + 动作页 N + 回归页 1 + 结束页 1 |
| 字幕 | 每页不超过 15 个英文词 |
| 体式 | 4–8 个，连续动作页不重复 |
| 故事弧线 | 出发 → 探索 → 高潮/登顶 → 回归 → 结束 |
| 身体强度 | 站姿探索 → 平衡挑战 → 高潮 → 坐姿回归 → 休息 |

## 3. 五种页面类型

| 类型 | 位置 | 功能 | 体式聚光灯 |
|------|------|------|------------|
| 场景页 | P1 | 标题、氛围、建立世界 | 无 |
| 过渡页 | P2 | 用感官细节进入情境，以问句引发好奇 | 无 |
| 动作页 | P3 至倒数第 3 页 | 每页一个情境、体式和语言目标 | 有 |
| 回归页 | 倒数第 2 页 | 放松并回顾旅程和语言目标 | 原则上无 |
| 结束页 | 最后一页 | 温暖道别与收尾 | 无 |

## 4. 动作页字段

每页必须保存：`subtitle`、`visualHint`、`poseLabel`、`teacherLanguage`、`expression`、`action`、`props`。

- `subtitle` 描绘情境，不直接命令做体式。
- `teacherLanguage` 为教师可照念的全英文讲稿，动作和语气提示使用中文括号标注。
- 体式必须能由情境自然触发，并通过身体逻辑检查。
- 有体式聚光灯时，主画面不重复出现 IP 角色；右侧呈现标准体式和英文体式名。

## 5. 教案结构

1. 活动概览。
2. 材料与准备。
3. 教学环节详解：导入、核心探索、回归放松。
4. 教学提示与差异化回应。
5. 附录：语言目标验证、体式对照表。
6. 教师速查卡。

## 6. 经典案例：A Walk in Wonder

- 11 页，自然探索主题。
- 核心词汇：field、grass、trees、forest、wind、leaves、rock、lake、river、mountain。
- 体式序列：Upward Salute → Tree Pose → Side Reach → Standing Balance → Seated Spinal Twist → Mountain Pose → Butterfly Pose → Savasana。
- 前端经典案例路径：`/workshop/interactive-yoga`。
- 静态演示资源：`public/demos/a-walk-in-wonder.html`。

## 7. 规范冲突记录

通用规范规定回归页不出现体式，但 A Walk in Wonder 定稿案例 P10 使用 Savasana。实现阶段保留定稿案例，同时新生成内容默认遵循通用规范；是否允许“休息体式作为回归页例外”需由教研最终裁定。

## 8. 验收重点

- 页面数量、类型顺序、字幕词数符合约束。
- 情境与体式之间存在自然的身体逻辑。
- 教师语言可直接照念，且与画面、动作、语言目标一致。
- 目标词汇和句型均在页面与教案附录中可追溯。
- 儿童安全标准同时遵循[瑜伽动作拆解与动捕规范](/wellbeing/yoga/action-standard)。
