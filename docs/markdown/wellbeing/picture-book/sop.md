# 绘本创作标准 SOP

> 从选题到成稿的完整制作流程与硬约束。绘本是「艺术表达引导手册」，不是沉浸式故事绘本——每一页都有互动引导功能。

## 1. 定位

每一页都承担引导功能，带领孩子完成：**情境进入 → 动手创作 → 语言输出 → 情感收束**。

配套产物：绘本（孩子看的）+ 教案（老师看的），两者页页对应。教案规范要点见本页第 7 节与 [脚本与分镜库](/wellbeing/picture-book/scripts)。

## 2. 硬约束（不可突破）

| 约束 | 数值 |
|------|------|
| 总页数 | 6-12 页，按语言目标数量和难度调节 |
| 每页词数上限 | ≤ 35 词（含对话气泡） |
| 单句长度上限 | ≤ 12 词 |
| 对话气泡单句 | ≤ 10 词 |
| 创作引导页词数 | ≤ 25 词/页 |
| 语言输出页 | 1 页，集中承载对话气泡，**必须有标题句**引导进入对话 |
| 标题句 | 1 句，≤ 8 词，自然衔接前页（创作完成），引出对话气泡 |
| 对话气泡 | 每种句型最多出现一次，用不同词汇覆盖而非重复句型 |
| 句子风格 | 短句分行，不写长段落 |

## 3. 五环节结构

| 环节 | 页数 | 功能 | 词数参考 |
|------|------|------|---------|
| ❶ 情境引入 | 1-2 页 | 建立共情，引入角色/场景 | 20-35 词 |
| ❷ 任务驱动 | 1 页 | 提出「我们来做…」任务 | 15-20 词 |
| ❸ 创作引导 | 1-2 页 | 视觉化步骤 + 随机机制 | 20-25 词/页 |
| ❹ 语言输出 | 1 页 | 标题句引入 + 对话气泡，目标句型 | 25-35 词 |
| ❺ 情感收束 | 1 页 | 简短有力，回到孩子 | 20-25 词 |

**绘本页上只呈现 1-2 页视觉化步骤框架，不写详细操作文字**——具体操作由老师在教案中掌握。

## 4. 创作引导核心原则（❸ 环节必含四要素）

| 要素 | 说明 | 范例 |
|------|------|------|
| 随机机制 | 掷骰子、抽盲袋、转盘、翻牌等，结果不可预知 | My Emo Friend 掷骰子定身体部位；A Pocket of Wild 盲袋抽材料 |
| 个性化 | 每人结果不同，没有标准答案 | 骰子点数不同 → emo friend 不同 |
| 悬念感 | 绘本页上营造「你会抽到什么？」 | 不展示最终结果，只展示「即将揭晓」 |
| 惊喜感 | 揭晓那一刻的 delight | 打开盲袋、翻开骰子、揭晓卡片 |

## 5. 主题库与材料库

### 5.1 主题库（10 个）

| # | 主题 | 适配场景 |
|---|------|---------|
| 1 | 情绪表达 | 认识情绪、表达感受 |
| 2 | 自然探索 | 户外、季节、自然现象 |
| 3 | 自我认知 | 身体、喜好、特长 |
| 4 | 人际关系 | 友谊、分享、合作 |
| 5 | 家庭与归属 | 家人、家、安全感 |
| 6 | 成长与变化 | 长大、变化、新阶段 |
| 7 | 感恩与善意 | 感谢、帮助、善意 |
| 8 | 身体与感知 | 五感、身体部位、动作 |
| 9 | 动物与生命 | 动物、生命、照顾 |
| 10 | 勇气与冒险 | 尝试、冒险、克服恐惧 |

每本绘本从主题库选 1-2 个主题，可扩充（需教研评审）。

### 5.2 材料库

| 类别 | 材料 |
|------|------|
| 绘画 | 画纸、彩笔/蜡笔、水彩 |
| 塑形 | 黏土/橡皮泥 |
| 拼贴 | 杂志/彩纸/胶水 |
| 自然材料 | 树叶/石头 |
| 回收材料 | 纸盒/瓶盖 |
| 纤维 | 毛线/布料 |
| 印刻 | 印章/印泥 |

未指定材料时，适配 2-3 种，与随机机制叠加放大个性化效果。

### 5.3 软空间（自由范围）

| 维度 | 自由范围 |
|------|---------|
| 主题 | 主题库 1-2 个，可扩充 |
| 角色 | 可人可动物，性别中性，可投射 |
| 艺术形式 | 绘画、拼贴、手工、黏土、自然材料等 |
| 叙事语气 | 温馨治愈，像耳语，不指令 |
| 书名 | 有文采、简短有留白，不照搬目标句型 |

## 6. 设计流程（六步）

1. **定主题 & 书名** → 从主题库选 1-2 个，起一个有文采的名字
2. **定语言目标** → 词汇 + 句型，确认覆盖策略
3. **定随机机制** → 创作引导的核心玩法，确保个性化 + 悬念
4. **定材料** → 从材料库选 2-3 种，与随机机制搭配
5. **写五环节** → 按结构模板逐页填充，语言输出页必须有标题句衔接前页
6. **逐页验算** → 词数 ≤ 35、对话气泡全句型覆盖、词汇全覆盖

## 7. 配套教案要点

教案是给引导师的操作手册，与绘本页页对应。完整框架：

```
一、教案元信息（书名/主题/语言目标/艺术形式/随机机制/时长/年龄/课前准备）
二、材料与准备（材料清单 / 环境准备 / 预制件说明）
三、分环节教学引导（对应绘本 P1-P7，每页含）
    氛围营造 · 分步话术（完整英文可照念）· 备选话术 · 接话策略 · 操作要点 · 时间
四、附录（分龄调整 / 常见问题应对）
```

**话术铁律**（老师拿来就能念，不需要自己组织英文）：

| 原则 | 说明 |
|------|------|
| 完整英文句子 | 写具体问句，不写「问孩子看到了什么」 |
| 给孩子选项 | 开放问题孩子答不出时给 2-3 个选项 |
| 过渡句独立标注 | 环节间用 `» TRANSITION` 标记，1-2 句 ≤ 15 词 |
| 备选话术 | 每段关键话术配 1 句备选 |
| 接话策略 | 写清孩子可能的回应 → 老师怎么接 |

**情境引入预热四模式**（每本绘本选一种，避免雷同）：

| 模式 | 感官入口 | 适合故事 |
|------|---------|---------|
| 🚶 身体行动式 | 动觉 | 旅途、探索、行动驱动 |
| 🖐️ 神秘触摸式 | 触觉 | 寻找、发现、秘密 |
| 👀 视觉锚点式 | 视觉 | 归属、邀请、等待、缺失 |
| 👂 声音引入式 | 听觉 | 神秘、自然、悬念 |

**环节流转与时间**：预热 2-3 min → 封面 1 min → P1-P2 共读 3-4 min → 任务驱动 1-2 min → 创作引导 15-20 min → 语言输出 5-8 min → 情感收束 2-3 min。

## 8. 制作流程（平台操作 SOP）

```
1. 知识库上传      上传课程资料 → 清洗 → 切片（700 字 / 100 重叠）→ Embedding → Qdrant
2. RAG 检索       按私有 + 公共资料过滤，返回上下文
3. 故事规划       LLM 生成：主题定位、语言目标、随机机制、五环节大纲
4. 分页文案       逐页生成（遵守第 2 节硬约束），逐页验算
5. 逐页配图       B9 绘本配图（多页一致）：角色、画风跨页一致
6. 教案生成       按 4E + 五环节框架生成配套教案
7. 审核验收       按第 9 节清单验收 → 归档至脚本库
```

配图规范遵循 [视觉风格与设计规范](/wellbeing/common/design-assets)（画风五选一，绘本常用 watercolor-storybook / crayon-collage；画幅 3:4）。

## 9. 验收清单

- [ ] 总页数 6-12，五环节齐全
- [ ] 每页词数 ≤ 35，单句 ≤ 12 词，气泡单句 ≤ 10 词
- [ ] 语言输出页有标题句（≤ 8 词），句型全覆盖、无重复句型
- [ ] 词汇全覆盖（正文 / 气泡 / Word Bank）
- [ ] 创作引导含随机机制四要素
- [ ] 书名有文采、不照搬句型
- [ ] 教案页页对应，话术完整可念，含过渡句与备选
- [ ] 配图画风统一、角色一致、儿童安全
- [ ] 已归档至 [脚本与分镜库](/wellbeing/picture-book/scripts)
