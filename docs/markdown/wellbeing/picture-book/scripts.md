# 绘本脚本与分镜库

> 绘本剧本的归档标准、分镜模板与已归档脚本索引。所有通过验收的绘本脚本必须按本页格式归档。

## 1. 归档格式（标准脚本文档结构）

每本绘本一个 Markdown 文档，按以下结构编写：

```markdown
# 绘本名（英文书名）

## 基本信息
| 项目 | 内容 |
|------|------|
| 主题 | 主题库中的 1-2 个主题 |
| 语言目标 | 词汇：…；句型：… |
| 随机机制 | 玩法简述（盲袋/骰子/转盘/翻牌 + 数量与对应关系） |
| 材料 | 材料清单 |
| 总页数 | N 页 |
| 画风 | watercolor-storybook / crayon-collage / … |
| 适用年龄 | 3-6 / 7-9 / 9-12 |
| 状态 | 草稿 / 已评审 / 已发布 |

## 逐页内容
**封面 — 书名**

**P1 · ❶ 情境引入**
（绘本正文文字）
`词数：N`

**P2 · ❶ 情境引入** ……（依此类推，标注所属环节）

## 验算
（词数表 + 词汇/句型覆盖表）

## 随机机制详情
（机制表格：编号 / 材料 / 可能代表 / 节奏）

## 配套教案
（链接或内嵌，遵循绘本 SOP 第 7 节框架）
```

## 2. 分镜字段规范

逐页分镜（用于 AI 配图与后续视频化）每页包含以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| page | 页码 + 环节 | P4 · ❸ 创作引导 |
| text | 页面最终文案 | Six bags, six secrets… |
| wordCount | 词数（≤ 35） | 18 |
| scene | 画面描述（中文，给审校看） | 桌面摆开六个编号盲袋，孩子围坐 |
| prompt | 生图 Prompt（含画风 + 角色 ID + 识别色） | watercolor-storybook, six numbered mystery bags on a wooden table, warm light, children's hands reaching… |
| ratio | 画幅 | 3:4 |
| refRole | 出场角色（可空） | — |
| status | 待生成 / 已生成 / 已审校 | 已审校 |

**Prompt 一致性要求**：多页绘本每页 Prompt 均携带相同的画风前缀与角色描述，保证 B9「绘本配图（多页一致）」效果。

## 5. 归档流程

1. 脚本通过 [绘本 SOP](/wellbeing/picture-book/sop) 第 9 节验收清单
2. 按第 1 节格式整理文档，补充分镜表
3. 在本页 3.3 节索引登记（书名/主题/状态/负责人/日期）
4. 状态流转：草稿 → 已评审（教研组）→ 已发布（配图完成并入库）
5. 任何修改递增版本（v2、v3…），不覆盖历史

## 6. 命名规范

```
脚本文档：{英文书名下划线连接}.md        例：A_Pocket_of_Wild.md
配图：    book-B9-{主题}-{页码}-v{N}.png 例：book-B9-wild-P04-v2.png
教案：    教案{书名}.md                  例：绘本教案范例A_Pocket_of_Wild.md
```

源文档存放于 `api/src/md/book/`；发布成品入素材库并打「绘本」标签。
