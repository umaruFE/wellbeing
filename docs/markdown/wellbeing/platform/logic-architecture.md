# 幸福力 AI 备课平台逻辑架构

> 本页是平台信息架构、菜单设计和业务归属的唯一基准。产品页面、权限、数据分类与 Wiki 目录均应与本页保持一致。

## 1. 平台定位

面向英语教师的一站式幸福力教学创作平台。统一用户心智模型：**经典案例可直接用 + 输入参数生成同款 + 在我的作品中管理和发布**。

## 2. 顶层信息架构

```
幸福力 AI 备课平台
├── 创作工坊     六类内容的新建入口
├── 我的作品     管理自己创建的内容
├── 灵感广场     浏览官方案例与教师公开作品
├── 教材库       教材、单元、章节及基础资源
└── 系统管理     用户、权限和平台设置
```

## 3. 创作工坊六个模块

| 模块 | 定位 | 主要子类 |
|------|------|----------|
| “英语+”融合活动 | 英语与艺术、体能、音乐融合 | 艺术表达、体感探索、音乐律动 |
| 能力训练 | 按技能维度创建幸福力化活动 | 语法、词汇、听力、口语、阅读、写作 |
| 趣味练习 | 把答题练习设计成游戏体验 | 密室闯关、侦探解谜、盲盒答题 |
| 完整课程 | 生成完整课程设计方案与 PPT | 课程概览、教案、课件、阅读材料 |
| 主题活动 | 节日与主题定制活动 | 节日、成长、动物、自然等主题 |
| 教学素材 | 面向教学场景的模板化素材生成 | Flash Card、四格漫画、体式引导图、单词图谱等 |

### “英语+”融合活动

| 路径 | 教学融合方式 | 经典类型 |
|------|--------------|----------|
| 艺术表达 | 视觉创作 + 情绪表达 | 艺术表达引导绘本 |
| 体感探索 | 身体叙事 + 语言嵌入 | [互动式情境瑜伽](/wellbeing/workshop/interactive-yoga) |
| 音乐律动 | 节奏 + 身体 + 语言 | [Music Star Quest](/wellbeing/workshop/music-star-quest)、歌曲编唱屋 |

## 4. 三类内容空间的对称关系

- **创作工坊**：新建内容。
- **我的作品**：管理已创建内容，子分类与创作工坊一致。
- **灵感广场**：发布和发现内容，分类与创作工坊一致。

标准流转：教师创作 → 保存到我的作品 → 发布到灵感广场 → 他人使用或改编 → 再创作。

## 5. 教材库联动

教材库按“教材 → 单元 → 章节”结构存储。每个创作入口均应支持“从教材选择”，自动解析章节的词汇、句型、语法和教学目标，减少重复输入。

## 6. 统一页面模式

每个创作模块至少包含：

1. 活动类型介绍及教学价值。
2. 官方经典案例，可直接进入课堂。
3. “生成同款”结构化参数表单。
4. 草稿保存到“我的作品”。
5. 后续编辑、删除、发布和使用统计能力。

当前前端落地范围与路由见[创作工坊前端实现说明](/wellbeing/platform/workshop-frontend-implementation)。
