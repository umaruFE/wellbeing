# 瑜伽动作拆解与动捕规范

> 体感/瑜伽教学内容的动作库标准：体式分级、动作要领模板、安全规范与动作捕捉技术要求。产出用于 IP 角色体能视频（V1）与瑜伽动画。

## 1. 定位与原则

- 瑜伽/体感内容服务于「体感探索」体验路径与 SEL 中的自我管理（呼吸、平静、身体觉察）
- 所有动作由 IP 角色示范（首选 Rolly，活力担当），教师口头引导，**不强行按压儿童身体**
- 动作设计遵循儿童生理特点：避免成人高强度体式，以游戏化、想象化语言引导

## 2. 动作分级（按年龄段）

| 级别 | 年龄段 | 单动作保持 | 单次总时长 | 特点 |
|------|--------|-----------|-----------|------|
| L1 | 3-6 岁 | 5-10 秒 | 3-5 min | 模仿动物、大肌肉群、坐姿/站姿为主 |
| L2 | 7-9 岁 | 10-20 秒 | 5-8 min | 平衡入门、简单串联（2-3 式流动） |
| L3 | 9-12 岁 | 20-30 秒 | 8-12 min | 平衡进阶、拜日式简化串联、呼吸配合 |

## 3. 标准动作库

### 3.1 体式分类

| 类别 | 体式（中/英） | 级别 | 教学口令意象 |
|------|--------------|------|--------------|
| 站姿 | 山式 Mountain | L1 | "Stand tall like a mountain" |
| 站姿 | 树式 Tree | L2 | "Grow your branches slowly" |
| 前屈 | 站立前屈 Standing Forward Fold | L2 | "Waterfall falling down" |
| 后弯(轻) | 猫牛式 Cat-Cow | L1 | "Arch like a cat, sink like a cow" |
| 坐姿 | 蝴蝶式 Butterfly | L1 | "Flap your butterfly wings" |
| 坐姿 | 鞋带式/简易盘坐 Easy Seat | L1 | "Sit like a calm frog" |
| 平衡 | 飞机式 Airplane | L2 | "Fly your arms wide" |
| 平衡 | 战士三式(简化) Warrior III | L3 | "Superhero take-off" |
| 力量 | 下犬式 Downward Dog | L2 | "Tent / upside-down V" |
| 放松 | 婴儿式 Child's Pose | L1 | "Rest like a seed" |
| 放松 | 挺尸式休息 Rest | L1 | "Starfish on the beach" |
| 呼吸 | 腹式呼吸 Belly Breath | L1 | "Balloon in your belly" |
| 呼吸 | 蜂鸣呼吸 Bee Breath | L2 | "Hum like a sleepy bee" |

### 3.2 禁止体式（儿童安全红线）

- 头倒立、肩倒立及一切颈部承重体式
- 深度后弯（轮式、鸽王式）
- 强力扭转与捆绑体式
- 憋气练习（呼吸练习全部为自然呼吸引导）
- 竞赛式保持（「看谁坚持得久」类指令）

## 4. 动作要领模板

每个入库动作必须填写完整要领卡：

```markdown
## {中文名} {English Name} · L{级别}

**口令（英文课堂语言）**：可照念的完整短句（≤ 12 词）
**意象**：动物/自然隐喻
**准备姿势**：从什么姿势进入
**分解步骤**：3-5 步，每步一个身体部位指令
**呼吸**：进入时吸/呼；保持时自然呼吸
**保持时长**：X-Y 秒（按级别）
**退出方式**：如何安全退出
**常见错误**：2-3 条 + 纠正引导语（不批评）
**禁忌**：何种身体状况不做
**示范角色**：Rolly（默认）/ 其他角色
```

**示例（树式 Tree · L2）**

```
口令："Stand tall. Now rest one foot on your leg. Grow your branches!"
分解：① 山式站立 ② 重心移至左脚 ③ 右脚掌贴左小腿内侧（禁压膝盖）④ 双手合十胸前或上举
呼吸：抬腿时呼气，保持时自然呼吸
常见错误：脚压膝盖 → 引导 "Put your foot on your leg, not your knee"
禁忌：踝/膝伤侧不承重
```

## 5. 动作捕捉（Mocap）规范

### 5.1 场地与设备

| 项目 | 要求 |
|------|------|
| 场地 | ≥ 4m × 4m，无反光杂物，均匀漫射照明 |
| 演员 | 体型与目标 IP 比例接近的成人演员（儿童体式由受过训练的成人示范者执行儿童化幅度） |
| 服装 | 贴身深色动捕服，无飘动饰物 |
| 标记点 | 全身 41 点标准布置（头 4 / 上肢 14 / 躯干 10 / 下肢 13），标记点不得被遮挡 |

### 5.2 采集参数

| 项目 | 标准 |
|------|------|
| 采样帧率 | ≥ 120 fps（保留慢放与节奏重配空间） |
| 标定 | 每次采集前 T-pose + W-pose 校准，误差 > 2mm 重标 |
| 每动作采集 | 静止 T-pose 5s + 完整动作 3 遍（快/中/慢）+ 退出过程 |
| 循环动作 | 首尾帧姿态误差 < 1°，保证无缝循环 |
| 数据清理 | 去抖动、补遮挡帧（插值）、脚底滑动修正（ground contact 锁定） |

### 5.3 骨骼绑定标准

- 骨骼层级采用平台标准人形骨架（与 IP 角色 3D 模型统一绑定）
- 命名：`Hips / Spine / Chest / Neck / Head / L/R Shoulder-Elbow-Wrist-Hand / L/R Hip-Knee-Foot-Toe`
- 面向：+Z 前方，Y 向上；单位米；IP 角色重定向时保持头身比（三头身）缩放映射
- 根运动：教学类动作为原地动作，烘焙时去除根位移（保留呼吸起伏）

## 6. 呼吸与节奏配乐

- 动作视频配 C2 活动背景乐（节奏 60-90 BPM）或 C6 冥想引导
- 收束放松统一 1-3 分钟 C6（Ace 或温润男声，语速 ≤ 0.85x）
- 呼吸口令与动作节拍对齐：4s 吸 - 2s 停 - 6s 呼起步（见[教育标准第 8 节](/wellbeing/common/pedagogy-standard)）

## 7. 动作入库与审核

1. 提交要领卡（第 4 节模板）+ 参考视频 + 动捕数据
2. 教研审核：安全性（第 3.2 红线）、口令可念性、年龄段匹配
3. 命名：`yoga-act-{英文体式名}-L{级别}-v{N}`，如 `yoga-act-tree-L2-v1`
4. 入库后同步更新动作库索引（本页 3.1 表）
5. 视频/动画产出流程见 [动画制作流水线](/wellbeing/yoga/animation-pipeline)
