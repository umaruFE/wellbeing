# 动画制作流水线

> 瑜伽/体感动画与教学视频的完整制作流程：分镜 → 图像生成 → 视频生成 → 配音配乐 → 合成交付，以及渲染、帧率与导出标准。

## 1. 流水线总览

```
① 动作库/脚本 → ② 分镜（Storyboard）→ ③ 分镜图片生成（ComfyUI）
→ ④ 视频片段生成（图生视频）→ ⑤ 配音（edge-tts）→ ⑥ 背景音乐 → ⑦ 合成与导出 → ⑧ 质检入库
```

产出两种标准视频资产：

| 类型 | 说明 |
|------|------|
| V1 IP 体能视频 | 单个 IP 角色示范动作（瑜伽/体感），对应图片 B11、视频 V1 |
| VM 多人叙事视频 | ≤ 3 角色同框叙事（三人版图生视频工作流） |

## 2. 各环节规范

### 2.1 分镜（Storyboard）

分镜表字段沿用[绘本分镜规范](/wellbeing/picture-book/scripts)并扩展：

| 字段 | 说明 |
|------|------|
| shot | 镜头号（S01、S02…） |
| duration | 镜头时长（2-6 秒/镜头，教学示范镜头可 8-10 秒） |
| action | 动作/表演描述（对应动作库 ID，如 `yoga-act-tree-L2`） |
| camera | 景别与运镜（固定机位优先；教学镜头正面固定 + 侧面补充） |
| text / voiceover | 屏幕文字 / 旁白文案（口令短句 ≤ 12 词） |
| imagePrompt | 首帧图生成 Prompt（画风 + 角色 ID + 识别色 + 场景） |
| videoPrompt | 图生视频运动描述（动作方向、幅度、节奏） |

分镜首帧必须先出图审校（角色一致性），通过后再提交视频生成。

### 2.2 分镜图片生成（ComfyUI）

- 工作流：`comfy/` 下分镜图片工作流（视频生成-生成分镜图片.json）
- 角色一致性：Prompt 固定携带角色 ID + 识别色 + 画风；同批次使用相同种子策略
- 画风五选一（见[视觉规范](/wellbeing/common/design-assets)），瑜伽类默认 clay-3d 或 cartoon-illustration
- 画幅：横版视频 16:9（1920×1080），竖版 9:16
- 单人视频需先产出角色基准图（生成人物图片工作流），再合入场景

### 2.3 视频片段生成（图生视频）

| 项目 | 标准 |
|------|------|
| 输入 | 已审校的分镜首帧图 + videoPrompt |
| 单镜头时长 | 2-6 秒（教学示范 8-10 秒） |
| 运动 | 幅度适中；角色动作以正面清晰可模仿为准，禁止快速甩镜 |
| 工作流 | n8n「图生视频」单人/三人主工作流：提交分镜图片请求 → 查询结果 → 继续生成视频请求 |
| 失败重试 | 任务中心重新提交；单镜头失败不影响其他镜头 |

### 2.4 配音（TTS）

- 引擎：edge-tts（n8n 生成配音工作流）
- 角色音色映射见[IP角色设定第 4 节](/wellbeing/common/character-setting)；Rolly 用活力音色 1.0x-1.1x，Ace 引导类 ≤ 0.85x
- 口令文案为完整英文短句；每镜头一条音轨，命名 `vo-{shotId}-{role}-v{N}`
- 呼吸引导类配音留 0.5s 起始静音，方便课堂对齐

### 2.5 背景音乐

- 类型与参数见[音频资源库](/wellbeing/music/audio-assets)：体感示范配 C2（60-90 BPM），收束放松配 C6
- BGM 音量比人声低 10-12 dB；冥想段落 BGM ≤ 15%

### 2.6 合成

- 片头：课程标题卡 ≤ 3 秒（模板背景图）
- 正片：镜头按时长拼接，动作示范镜头旁保留字幕口令（与 C3 跟读一致的句式）
- 片尾：固定仪式画面（角色击掌/彩虹手势）+ 核心隐喻句
- 音轨：旁白 > 音效 > BGM 的响度优先级，成品 -16 LUFS ±2

## 3. 3D / 2D 渲染标准

### 3.1 3D 路线（动捕驱动）

| 项目 | 标准 |
|------|------|
| 源数据 | 动捕 120fps（见[动捕规范](/wellbeing/yoga/action-standard)） |
| 骨骼重定向 | 动作 → IP 三头身角色，保持识别色与比例 |
| 渲染帧率 | 30fps 输出（120fps 源允许 2x-4x 慢放不卡顿） |
| 灯光 | 三点布光，柔和阴影；角色受光均匀无死黑 |
| 材质 | 哑光质感（黏土/硅胶感），符合儿童审美 |
| 循环 | 循环动作首尾帧误差 < 1°，交叉淡化 ≤ 100ms |

### 3.2 2D / AI 生成路线

| 项目 | 标准 |
|------|------|
| 帧率 | 24-30fps |
| 关键帧 | 动作起始/极点/结束三关键帧必须清晰（教学可读性优先） |
| 风格抖动 | 同镜头内画风、角色特征漂移需重新生成 |
| 运动模糊 | 教学示范镜头关闭运动模糊，保证动作清晰 |

## 4. 导出格式标准

| 用途 | 格式 | 参数 |
|------|------|------|
| 平台播放/课件插入 | MP4 (H.264 + AAC) | 1920×1080，30fps，码率 8-12 Mbps，-16 LUFS |
| 竖版（移动端） | MP4 | 1080×1920，30fps |
| 二次编辑母版 | ProRes 422 或 PNG 序列 | 1080p 全帧率 |
| 序列帧 | PNG | 命名 `{shotId}_f{帧号4位}.png` |
| 封面 | PNG | 取代表帧，1920×1080 |

文件命名：`yoga-V1-{动作ID}-v{N}.mp4`、`video-VM-{主题}-v{N}.mp4`。

## 5. 质检清单

- [ ] 分镜表字段完整，首帧图全部审校通过
- [ ] 角色形象跨镜头一致（识别色/比例/画风无漂移）
- [ ] 动作与动作库要领卡一致，无禁止体式
- [ ] 口令字幕与配音文案一致，无错别字
- [ ] 响度达标（-16 LUFS ±2），人声清晰不被 BGM 压制
- [ ] 成片时长符合级别（L1 3-5 min / L2 5-8 min / L3 8-12 min）
- [ ] 导出参数符合第 4 节，命名规范，已入素材库（类型标签「体能」或「教学动画」）
- [ ] AIGC 标识已按规定添加
