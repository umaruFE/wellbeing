# 课件交互与动画逻辑

> 课件编辑器与课堂放映的交互行为标准：画布操作、快捷键、自动保存、触发逻辑与动画时序。

## 1. 画布编辑交互

### 1.1 图层基础操作

| 操作 | 行为标准 |
|------|---------|
| 拖拽 | 选中图层后拖动，实时显示坐标 |
| 缩放 | 四角手柄等比缩放；侧边手柄单轴缩放（文本框禁止单轴，防止字体变形） |
| 旋转 | 顶部旋转手柄，支持角度吸附（每 15°） |
| 对齐 | 拖拽时显示智能辅助线与吸附（画布中线、其他图层边缘） |
| 层级 | 置顶/上移/下移/置底；选中图层可居中、适应画布 |
| 文本 | 双击进入编辑，支持字体/字号/粗细/颜色/对齐/行高/字间距/描边 |

### 1.2 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + Z / Ctrl + Y | 撤销 / 重做（历史栈 50 步） |
| Ctrl + D | 复制选中图层 |
| Delete | 删除选中图层 |
| 方向键 | 移动 1pt；Shift + 方向键加速 10pt |
| Esc | 取消选中 / 退出文本编辑 |

### 1.3 幻灯片操作

添加 / 删除 / 复制 / 设为背景 / 取消背景转图层。设为背景后该图不参与选中与导出图层。

## 2. 保存与历史

| 机制 | 标准 |
|------|------|
| 自动保存 | 画布数据变更后防抖保存至后端（独立于教案数据） |
| 本地兜底 | 网络异常时写入 localStorage，恢复后提示合并 |
| 历史版本 | 页面级历史记录，可查看并恢复到任一历史版本 |
| 撤销栈 | 单次会话最多 50 步，刷新后清空（历史版本不受影响） |

## 3. 课堂交互触发规范

### 3.1 触发方式

| 触发 | 用途 | 规范 |
|------|------|------|
| 单击播放 | 音频/视频素材默认行为 | 单击即播/再点暂停；显示进度条（音频卡片带波形） |
| 点击触发 | 揭晓类交互（翻卡、答案显示） | 点击区域为整个卡片；触发后 300ms 内不重复响应（防连点） |
| 拖拽填词 | 歌曲编唱屋 Word Bank 拖入空格 | 拖拽物吸附到最近空格；空格已占用则弹回原位 |
| 悬停预览 | 图片放大提示 | 悬停 500ms 触发，移出即消 |

### 3.2 答题反馈规范（与「无标准答案」原则一致）

| 反馈 | 视觉 | 听觉 | 文案 |
|------|------|------|------|
| 正确 | 星星/彩虹动效 + 高亮 | 上行 chime | "Great! / You found it!" |
| 再试一次 | 轻微晃动 + 暖色描边（非红色叉） | 轻柔 boing | "Try again! / Almost!" |
| 开放作答 | 无对错判定，直接展示孩子的选择 | sparkle | "That's YOUR answer!" |

**禁止**：刺耳错误音、红色大叉、"Wrong!" 字样、排名羞辱类反馈。

### 3.3 经典活动交互模板

教案「经典活动」库对应的课件交互模式：

| 活动 | 交互模式 |
|------|---------|
| Bingo | 点击格子标记，横/竖/斜连线索自动判定庆祝 |
| 猜单词 | 逐字母点击揭示，含步数统计 |
| 情景对话 | 角色头像点击播放 C4 对话音频，气泡逐条出现 |
| 闪卡翻转 | 点击 3D 翻转（正面图 / 反面词），支持批量 B3 卡组 |
| 拼图阅读 | 拖拽段落排序，落位吸附 |
| 我画你猜 | 画板模式 + 计时器 |

## 4. 动画时序规范

### 4.1 通用时序

| 动画 | 时长 | 缓动 |
|------|------|------|
| 进入（淡入） | 300ms | ease-out |
| 进入（弹跳） | 400ms | ease-out-back |
| 强调（脉冲/晃动） | 500ms | ease-in-out |
| 退出（淡出） | 200ms | ease-in |
| 翻卡 3D | 400ms | ease-out |
| 页面切换 | 350ms | ease-in-out |

### 4.2 序列规则

- 同页动画串行间隔 150-200ms，避免同时爆炸式出现
- 标题先于正文出现；正文先于配图
- 音效与视觉动效同时触发（误差 ≤ 50ms）
- 冥想类页面（C6）禁用弹跳动效，只允许缓慢淡入（600ms）

### 4.3 节奏类动画

- 跟唱音频的歌词高亮按句切换，切换点与音频时间轴对齐（0.75x/1x/1.25x 变速时同步换算）
- 乐器演奏信号：指定歌词词位触发乐器图标弹跳

## 5. 任务中心与异步生成

| 机制 | 标准 |
|------|------|
| 队列刷新 | 每 5 秒自动轮询任务状态 |
| 任务状态 | 等待中 → 进行中 → 已完成 / 失败 / 已取消 |
| 进度展示 | 任务卡片含类型图标、数量、进度条；详情含提示词与参数配置 |
| 完成动作 | 「插入画布」直接落到当前页；或转存素材库 |
| 失败处理 | 支持重新提交；失败原因在详情中可见 |

素材生成向导（图片 B1-B13 / 视频 V1、VM / 音频 C1-C6）参数见 [课件模板第 4 节](/wellbeing/courseware/template) 与各资源规范页。

## 6. 性能与兼容

- 单页图层数建议 ≤ 30；超出时提示拆页
- 视频素材占位加载，点击后才拉取全量资源
- 画布缩放期间降级渲染（隐藏细描边），松手后重绘
- 导出 .pptx 为静态布局 + 媒体附件（交互与动画保留在平台放映模式）

## 7. 交互验收清单

- [ ] 所有点击区域 ≥ 44×44pt（儿童触控友好）
- [ ] 防连点保护生效（300ms 节流）
- [ ] 反馈符合 3.2 规范，无否定性羞辱反馈
- [ ] 动画时序符合 4.1-4.2，冥想页无弹跳
- [ ] 音视频可播放、进度可见、变速正确
- [ ] 自动保存与 localStorage 兜底验证通过
- [ ] 任务中心失败任务可重试并正常插入画布
