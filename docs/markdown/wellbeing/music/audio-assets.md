# 音效与配乐资源库

> 平台音频资产分类、内置资源清单、音色库、命名与授权规范。所有音频素材的入库、检索、使用以本页为准。

## 1. 音频资产分类

素材库音频类型标签固定为四类：**BGM / 旁白 / 歌曲 / 音效**。

### 1.1 课件音频素材（AI 生成六类）

| 编号 | 类型 | 说明 | 默认参数 |
|------|------|------|---------|
| C1 | 情绪氛围 BGM | 环节背景氛围铺底 | 循环、音量 20-30%、无人声 |
| C2 | 活动背景乐 | 游戏/创作环节伴奏 | 节奏明快、循环 |
| C3 | 跟读音频 | 词汇/句型示范跟读 | TTS 清晰人声、语速 0.9x |
| C4 | 对话音频 | 角色情景对话 | 双角色音色区分、加情绪标注 |
| C5 | 主题歌曲 | 课程主题曲 | 遵循[编曲规范](/wellbeing/music/composition-guide) |
| C6 | 冥想引导 | 呼吸/身体扫描引导 | Ace 或温润男声、语速 ≤ 0.85x、BGM 音量 ≤ 15% |

### 1.2 使用场景映射

| 教学场景 | 推荐类型 |
|---------|---------|
| 课堂进入 / 情境引入（Engage） | C1 情绪氛围 |
| 游戏 / 创作环节（Execute） | C2 活动背景乐 |
| 词汇教学 / 句型操练 | C3 跟读 |
| 故事共读 / 角色扮演 | C4 对话 |
| 音乐律动路径 | C5 主题歌曲 |
| 收尾静心 / 瑜伽放松（Elevate） | C6 冥想引导 |

## 3. 音频技术规范

| 项目 | 标准 |
|------|------|
| 分发格式 | MP3（素材库/课件引用） |
| 采样率 / 位深 | 44.1kHz / 16bit |
| 声道 | 立体声（人声类允许单声道） |
| 响度 | 成品 -16 LUFS ±2；BGM 铺底比人声低 10-12 dB |
| 循环 | BGM 必须做首尾无缝循环（淡入淡出 ≤ 50ms 交叉） |
| 时长 | 音效 ≤ 5s；C1/C2 循环段 30-60s；C6 冥想 1-3 min |
| 文件头 | 上传时自动补全时长、波形数据（素材库卡片可视化用） |

## 4. 命名与入库规范

```
{模块}-{类型}-{主题}-{描述}-v{N}.mp3

示例：
ppt-C1-forest-morning-loop-v1.mp3     森林早晨氛围 BGM
ppt-C6-breathing-calm-3min-v1.mp3     3 分钟呼吸冥想引导
music-C5-sky-insong-v2.mp3            主题歌曲成品
sfx-correct-chime-v1.mp3              答题正确音效
```

入库要求：

- 来源标签：AI 生成 / 手动上传 / 课程生成
- 类型标签：BGM / 旁白 / 歌曲 / 音效（四选一）
- 关联课程（可选）；AI 生成记录提示词与参数，便于复现
- 音频库卡片支持波形预览与进度播放，上传后需试听检查爆音/截幅

## 6. 常用音效速查（课件/游戏反馈）

| 场景 | 音效 | 规格 |
|------|------|------|
| 答题正确 | 上行双音 chime | ≤ 1s |
| 答题错误 | 轻柔「boing」（非否定性刺耳声） | ≤ 1s |
| 翻卡 / 揭晓 | 短 whoosh + sparkle | ≤ 1.5s |
| 计时提醒 | 轻敲木鱼 ×2 | ≤ 1s |
| 完成/通关 | 欢快短旋律 | ≤ 3s |

规范：错误反馈音效不得刺耳或带有嘲笑感（与「无标准答案」原则一致）。

## 7. 维护流程

1. 新音频入库：按第 4 节命名 → 上传素材库 → 打标签 → 试听检查
2. AI 生成音频：任务中心完成后「插入画布」或转入素材库
3. 每季度盘点：清理无引用的临时资产；被课程引用的资产不可删除
4. 音色/乐器新增需音频组评审，并同步更新本页与角色设定页
