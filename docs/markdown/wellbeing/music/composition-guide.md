# 编曲与作词规范

> 歌曲编唱屋的旋律模板、填词硬约束、词曲审核标准与配套教案框架。歌曲定位：学生从「听歌的人」变成「写歌的人」。

## 1. 旋律模板库（四选一）

平台内置 4 首公版旋律作为填词基底（伴奏资源见 [音效与配乐资源库](/wellbeing/music/audio-assets)）：

| 旋律 | 情感基调 | 结构 | 适用主题 |
|------|---------|------|---------|
| Edelweiss | 温柔、治愈 | 8 行，AABA 变体 | 情绪表达、感恩、平静 |
| Twinkle Twinkle Little Star | 明亮、童趣 | 6 行分节 | 自然探索、认知启蒙 |
| If You're Happy | 活力、律动 | 分节 + 动作句 | 身体感知、运动热身 |
| You're My Sunshine | 温暖、深情 | 8 行 | 家庭归属、友谊 |

## 2. 填词硬约束（以 Edelweiss 为标准模板）

```
行号  结构                                  音节        旋律特征
─────────────────────────────────────────────────────────────
L1    Edelweiss, Edelweiss                  3+3         轻柔起句，下行收
L2    Every morning you greet me            6-8         流动铺展
L3    Small and white, clean and bright     3+3         呼应 L1，明亮上扬
L4    You look happy to meet me             6-8         呼应 L2，收束
L5    Blossom of snow may you bloom and grow 7-10       ★旋律最高点，情感峰
L6    Bloom and grow forever                6-8         从高峰回落
L7    Edelweiss, Edelweiss                  3+3         回归起句，点题句位置
L8    Bless my homeland forever             7-8         最终落定，收束句位置
```

| 约束 | 说明 |
|------|------|
| 总行数 | 固定 8 行 |
| L1 / L3 / L7 | 3+3 对仗结构 |
| L5 | 全曲最长行，**旋律最高点**，放情感升华或核心句型 |
| L7 | **点题句**，呼应歌名，承载核心隐喻 |
| L8 | **收束句**，一句总结，不设空格 |
| 每行最多空格 | 1 个 |
| 空格总行数 | ≤ 4 行（建议 L2/L4/L5/L6；L7/L8 固定） |
| 空格位置 | **不放在行末**，保证固定尾词可押韵 |
| 空格预留音节 | 取 Word Bank 中位数，最坏允许略超 1 音节靠唱法调整 |
| 句式 | 避免同一句式重复，每行句式应有变化 |
| Word Bank | 词汇量 = 空格数 + 2-3 个干扰词 |

## 3. 软空间

| 维度 | 自由范围 |
|------|---------|
| 主题 | 与课程主题联动（情绪/自然/身体/家庭…） |
| 空格位置 | 任意行（建议 L2/L4/L5/L6） |
| L1+L3 策略 | 互相呼应或递进（形容词对、名词对、动词对均可） |
| 语言目标嵌入 | 可嵌入介词、动词、形容词、句型 |
| 歌名 | 有文采、简短有留白，不照搬目标句型 |

## 4. 填词设计流程（六步）

1. **先定歌名 & L7 点题句** → 核心隐喻是什么？用 3+3 写出来
2. **再定 L8 收束句** → 一句升华，7-8 音节，锚定情感
3. **定 L5 高潮行** → 旋律最高点承载语言目标的核心句型
4. **定 L1+L3 对仗策略** → 呼应还是递进，决定整首歌语调
5. **分配空格** → L2/L4/L5/L6 中选 3-4 行各设一空，句式不重复、空不在行末
6. **逐行验算音节** → 固定音节 + 空格预留 ≤ 旋律约束，标注每行音节数

### 范例：A Sky Inside（旋律 Edelweiss）

```
L1: Feelings come, feelings go            [固定 6]
L2: I am ___ , I will say                 [固定 6 + 空≤2 = 8]
L3: Big and small, fast and slow          [固定 6]
L4: When I'm ___ I sing a song            [固定 5 + 空≤2 = 7]
L5: Sometimes ___ and that's okay         [固定 5 + 空≤2 = 7] ★高潮
L6: Tell me, are you ___ today?           [固定 6 + 空≤2 = 8]
L7: Feelings come, feelings go            [固定 6 点题]
L8: Every feeling, let it show            [固定 8 收束]
```

| 要素 | 值 |
|------|----|
| 空格数 | 4 个 |
| Word Bank | happy, sad, angry, tired, shy, excited, bored（7 词 = 4 空 + 3 干扰） |
| 语言目标 | How do you feel? I feel… |
| 押韵 | A 韵 go/slow/go/show 首尾贯穿，B 韵 say/okay/today 中间三句 |
| 句式 | L2 陈述 / L4 条件 / L5 接纳 / L6 反问，四种不重复 |

## 5. 编曲规范

| 项目 | 标准 |
|------|------|
| 调性 | C / G / F 大调为主，避免升降号多的调；同一首不转调 |
| 速度（BPM） | 摇篮曲类 60-76；跟唱类 88-104；律动类 108-120 |
| 节拍 | 4/4 为主，If You're Happy 允许 6/8 变体 |
| 和声 | 三和弦为主，副歌最多加一个七和弦；禁用小调阴暗和声铺满全曲 |
| 配器 | 儿童歌曲以尤克里里/木吉他/钢琴/口哨/打击乐为主，音色明亮 |
| 前奏/间奏 | 前奏 ≤ 4 小节，间奏 ≤ 8 小节，保留人声主导 |
| 变速版本 | 每首产出 0.75x / 1x / 1.25x 三档（变速脚手架原则） |
| 立体声 | 人声居中，伴奏左右分布；导出 44.1kHz / 16bit MP3 |

**BGM 生成**（C1/C2 类）遵循 [音频资源库](/wellbeing/music/audio-assets) 分类规范。

## 6. 词曲审核标准

- [ ] 行数、音节、对仗结构符合所选旋律模板硬约束
- [ ] 空格 ≤ 4 行、每行 1 空、不在行末
- [ ] Word Bank = 空格数 + 2-3 干扰词，词汇全部在课程核心词汇内
- [ ] 句式不重复；押韵有设计（首尾韵贯穿）
- [ ] L7 点题句承载核心隐喻；L8 收束不设空格
- [ ] 无暴力/恐怖/负面暗示词汇；情绪词全部「值得被听见」式接纳
- [ ] 歌名有文采，不照搬目标句型
- [ ] 三档变速版本已产出
- [ ] 配套教案按第 7 节完成

## 7. 配套教案框架（歌曲编唱屋五步流程）

完整框架源文档：`api/src/md/audio/歌曲编唱屋 · 通用教案标准与框架.md`。

```
基础信息 → 教学目标 → 五步活动流程 → 教学建议 → 附录
```

| 板块 | 要求 |
|------|------|
| 基础信息 | 适用年龄 / 英文水平 / 建议人数 / 活动时长（15-25 min） |
| 教学目标 | 英文目标 + 幸福力目标 + 产出物，三条并行 |
| 五步流程 | 每步含时间（精确到 0.5min）/ 目标 / 操作 / 中英双语教学引导 |
| 教学建议 | 表格 ≥ 4 条，覆盖参与度/选择/节奏/纪律问题 |
| 附录 | 核心句型（标注语法结构）+ 核心词汇（词性 + 中文，分组） |

### 五步速览

```
一 感知热身（约 5 min）   感官配对激活：主题元素 ↔ 乐器/动作/声音
二 歌曲创编（约 8 min）   2.1 熟悉旋律(0.5) → 2.2 理解歌词结构(2) → 2.3 集体填词(5-6) ★核心
三 学唱练习（约 5 min）   3.1 慢速跟唱 0.75x(3) → 3.2 提速练习 1x(2)
四 完整演出（约 3 min）   4.1 分配乐器(0.5) → 4.2 带乐器表演(2) → 4.3 再来一遍(0.5)
五 主题收尾（约 2 min）   5.1 核心句型分享(1-2) → 5.2 隐喻句总结 + 固定仪式(1)
```

**填词铁律**：不纠正孩子的选择——这是他们的表达，没有「正确」答案。核心话术反复强调："There's no wrong answer! This is YOUR song."

**乐器演奏信号**：每行歌词末尾圆圈填乐器图标（每行最多 2 种）；约定「引导师举手 = 全体停止」。
