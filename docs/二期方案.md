## 一、一期总结

### 1.1 产品定位

面向少儿英语教育的 **AI 驱动课程创作与管理平台**（CourseGen AI），帮助教师通过 AI 快速生成课程、教案、PPT 课件、绘本、歌曲及教学素材。

### 1.2 核心能力

| 能力 | 说明 |
|---|---|
| AI 课程生成 | 输入主题/年龄/语言点 → AI 生成完整课程（目标、情境、旅程） |
| AI 教案设计 | 基于 4E 教学法（Engage/Empower/Execute/Elevate）生成教案 |
| AI PPT 课件 | 逐页生成英文内容 + 布局坐标，支持三栏画布编辑器 |
| AI 绘本制作 | RAG 知识库驱动，多页 AI 配图，批量生成 |
| AI 歌曲编排 | 英文儿歌生成 + 填词模板 + 活动方案 |
| AI 素材生成 | 图片（ComfyUI）、音频（TTS/BGM）、视频（图生视频/文生视频） |
| LoRA 微调 | IP 角色风格微调，训练专属画风模型（Poppy/Edi/Rolly/Milo/Ace） |
| 绘本知识库 | 文档上传（docx/pdf/txt）→ 按分类检索 → 生成时引用 |

### 1.3 技术架构

```
前端 (React 19 + Vite + Ant Design + Tailwind, PWA)
↕
后端 (Next.js 14 API Routes, 端口 4000)
↕
PostgreSQL 16 + n8n 工作流引擎 + ComfyUI (GPU) + DashScope (Qwen)
```

## 四、模块一：企业级知识库

### 4.1 目标

一期绘本知识库仅支持简单分类 + 全文拼接。二期升级为 **多层级、多格式、智能检索** 的企业级知识中枢。

### 4.2 功能设计

| 功能 | 说明 |
|---|---|
| **多级目录管理** | 机构 → 学部 → 学科 → 知识库目录，支持拖拽排序、批量操作 |
| **多格式支持** | docx / pdf / txt / md / excel / ppt / 图片（OCR 提取） |
| **细粒度权限** | 公开库（全员可用）、部门库（仅本部门）、私有库（仅本人） |
| **智能检索** | 全文搜索 + 语义搜索（向量召回），支持组合筛选 |
| **知识关联** | 文档之间可建立关联（如：教案 ↔ 课标 ↔ 评价标准） |
| **版本管理** | 文档更新后保留历史版本，可回溯对比 |
| **AI 引用溯源** | 生成内容时标注引用了哪些知识文档，支持点击跳转原文 |
| **知识图谱** | 自动提取文档中的实体和关系，构建知识图谱可视化 |

### 4.3 技术方案（LLM Wiki）

采用 **Wiki + LLM** 方案，将知识库构建为智能 Wiki 系统，LLM 负责内容理解、检索、问答和自动整理。

```
┌──────────────────────────────────────────────────────┐
│                  LLM Wiki 架构                        │
├──────────────────────────────────────────────────────┤
│                                                      │
│  用户层                                               │
│  ├── Wiki 浏览器（目录树 / 全文搜索 / 语义搜索）         │
│  ├── AI 问答（"这份教案符合课标吗？"→ Wiki 检索 + 回答） │
│  └── AI 写作助手（生成时自动引用 Wiki 条目）              │
│                                                      │
│  LLM 智能层                                           │
│  ├── 自动摘要：上传文档 → LLM 生成摘要 + 关键词           │
│  ├── 自动分类：LLM 分析内容 → 推荐分类目录                │
│  ├── 自动关联：LLM 发现文档间关联 → 构建知识网络           │
│  ├── 语义检索：问题 → Embedding → 向量召回 → LLM 重排     │
│  ├── 内容质检：LLM 检查知识准确性、时效性、冲突检测        │
│  └── 智能问答：RAG 检索 → 多模型路由 → 生成 + 引用溯源    │
│                                                      │
│  Wiki 存储层                                          │
│  ├── Wiki 条目（标题、正文、分类、标签、版本历史）         │
│  ├── 向量索引（Embedding：bge-large-zh / text-embedding）│
│  ├── 关系图谱（文档间引用、关联、冲突关系）                │
│  └── 权限控制（公开 / 部门 / 私有）                       │
│                                                      │
└──────────────────────────────────────────────────────┘

知识文档上传流程：
  文档上传 → 文本提取（docx/pdf/ocr）
    → LLM 生成摘要 + 提取关键词 + 推荐分类
    → 切片 → Embedding → 向量索引
    → 自动关联已有条目 → 发布到 Wiki

AI 生成时引用流程：
  用户请求 → 语义检索 Wiki → Top-K 召回
    → LLM 重排序 → 注入 Context
    → 多模型路由生成 → 标注引用来源（可点击跳转 Wiki 条目）
```

## 五、模块二：个人 AI Agent

### 5.1 目标

每位教师培养一个 **"越用越懂你"** 的 AI 助手，学习其教学风格、偏好、学情特点，辅助备课和授课。

### 5.2 功能设计

| 功能 | 说明 |
|---|---|
| **风格画像** | 自动分析教师历史作品（教案/PPT/绘本），提取风格特征（用词偏好、活动设计风格、视觉偏好） |
| **个性化生成** | AI 生成内容时自动融入教师风格，不再"千篇一律" |
| **偏好设置** | 教师可手动设置偏好（教学理念、常用活动类型、默认难度、语言风格） |
| **学情记忆** | 记录教师教授的班级、学生反馈、教学调整历史，生成时考虑学情 |
| **智能推荐** | 根据教师习惯推荐教学模板、素材、活动方案 |
| **对话式交互** | 支持"帮我改一下第三页的活动"式的自然语言编辑 |
| **Agent 共享** | 教师可导出自己的 Agent 配置，分享给同事 |
| **多模型驱动** | Agent 底层支持切换不同大模型（GPT-4o / Claude / Qwen / 本地模型） |

### 5.3 技术方案（Hermes Agent）

采用 **Hermes Agent** 架构，以 LLM 为核心大脑，通过 Function Calling 驱动各类工具，实现自主感知、记忆、规划和执行。

```
┌──────────────────────────────────────────────────────┐
│                 Hermes Agent 架构                      │
├──────────────────────────────────────────────────────┤
│                                                      │
│  ┌──────────┐  交互层：自然语言对话 / 生成请求          │
│  │  用户交互  │  "帮我改一下第三页的活动"               │
│  └────┬─────┘                                        │
│       │                                              │
│  ┌────▼─────────────────────────────────┐            │
│  │         Agent 大脑（LLM Core）         │            │
│  │  · 意图理解：理解教师自然语言指令        │            │
│  │  · 任务规划：拆解为子任务               │            │
│  │  · 工具选择：决定调用哪些工具            │            │
│  │  · 结果整合：汇总工具返回 → 输出         │            │
│  │  模型：Qwen-Plus / GPT-4o / Claude     │            │
│  │        （通过多模型路由层选择）           │            │
│  └────┬─────────────────────────────────┘            │
│       │                                              │
│  ┌────▼─────────────────────────────────┐            │
│  │         记忆系统（Memory）              │            │
│  │  · 风格画像：教师用词/活动/视觉偏好       │            │
│  │  · 短期记忆：当前会话上下文              │            │
│  │  · 长期记忆：历史作品特征、学情数据       │            │
│  │  · LLM Wiki 检索：实时获取知识库内容      │            │
│  └────┬─────────────────────────────────┘            │
│       │                                              │
│  ┌────▼─────────────────────────────────┐            │
│  │      Function Calling（工具集）         │            │
│  │  · generate_lesson_plan()  生成教案     │            │
│  │  · generate_ppt()          生成 PPT     │            │
│  │  · generate_picture_book() 生成绘本     │            │
│  │  · search_wiki(query)      检索知识库   │            │
│  │  · generate_image(prompt)  生成图片     │            │
│  │  · edit_slide(page, action) 编辑页面    │            │
│  │  · analyze_style()         分析教师风格  │            │
│  │  · recommend_template()    推荐模板     │            │
│  └──────────────────────────────────────┘            │
│                                                      │
└──────────────────────────────────────────────────────┘

工作流程：
  教师日常使用（备课/生成/编辑）
    → 行为埋点记录到 agent_interactions
    → 每日定时任务：LLM 分析近期作品 → 提取风格标签 → 更新 agent_profiles

  Agent 生成请求时：
    1. 教师发出指令（自然语言或点击生成按钮）
    2. Agent 大脑（LLM）理解意图 + 规划任务
    3. 加载记忆：风格画像 + 学情记忆 + 偏好设置
    4. 检索 LLM Wiki 获取知识库参考
    5. 通过 Function Calling 调用对应工具执行
    6. 汇总结果 → 输出个性化内容

Agent 与一期系统的关系：
    一期的"生成按钮"= Agent 的一个 Function Call
    二期的"对话式交互"= 直接和 Agent 聊天，Agent 自主决定调用哪些工具
```

**风格画像维度**：

```json
{
  "language_style": "简洁活泼 | 学术严谨 | 温馨鼓励",
  "activity_preference": ["游戏化", "小组合作", "角色扮演"],
  "difficulty_default": "中等偏上",
  "visual_style": "色彩鲜艳 | 简约清新 | 手绘风",
  "common_phrases": ["Let's explore", "Can you try"],
  "average_content_length": "medium",
  "interaction_frequency": "high"
```

## 六、模块三：在线授课系统

### 6.1 目标

从 **"备课工具"** 延伸到 **"上课工具"**，支持教师直接在平台上授课，学生通过链接/设备参与互动。

### 6.2 功能设计

| 功能 | 说明 |
|---|---|
| **课堂创建** | 从课程/PPT 一键创建课堂，设置上课时间、班级 |
| **实时投屏** | 教师端投屏 PPT/绘本，学生端同步观看 |
| **互动活动** | 答题、投票、连线、拖拽填空、抢答等课堂互动 |
| **学生反馈** | 实时表情反馈（懂了/没懂/有趣）、举手提问 |
| **AI 课堂助手** | 实时转录教师讲解 → AI 生成课堂笔记 → 课后自动总结 |
| **课堂录制** | 自动录制课堂过程（屏幕 + 语音），课后回放 |
| **课堂报告** | 课后自动生成出勤、参与度、互动数据报告 |
| **作业布置** | 课后布置作业，学生在线提交，AI 辅助批改 |

### 6.3 技术方案

```
教师端                               学生端
  │                                    │
  ├── Socket.io ───────────────────────┤  实时同步（翻页/互动/状态）
  ├── WebRTC (可选) ───────────────────┤  音视频直播
  ├── 静态资源 CDN ────────────────────┤  PPT/图片加载
  │                                    │
  ▼                                    ▼
        授课服务（新增）
  ├── Socket.io Server（实时通信）
  ├── Redis（课堂状态 / Session / 房间管理）
  ├── 录制服务（可选 Media Server / 屏幕录制 API）
  ├── AI 转录服务（Whisper / DashScope 语音识别）
  └── 课后报告生成（多模型路由 → 自动选择模型）
```
